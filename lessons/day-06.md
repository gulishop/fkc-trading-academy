# Day 6 — If-Else (Decision Making)

- **Concept:** Program ko faisla lena sikhana
- **Example:**
  ```python
  age = int(input("Age batayen: "))
  if age >= 18:
      print("Aap bade ho")
  else:
      print("Aap bache ho")
  ```
- **Practice:** Number check karwayen ke positive hai ya negative
- **Mini Project:** "Pass/Fail Checker" — marks input karke pass/fail bataye (40 se kam = fail)
