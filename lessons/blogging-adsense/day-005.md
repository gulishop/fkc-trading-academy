# Day 5 — **Blog Images Ko Professional Banane Ke 10 Asaan Tarike (Formatting + Optimization)**

**Concept:**
Aaj hum seekhenge ke blog ke images ko kaise attractive, fast-loading aur SEO-friendly banaya jaye. Sahi formatting se user experience improve hoti hai, aur Google bhi images ko rank karta hai. Hum cover karenge: image size optimization, alt text, lazy loading, captions, aur WordPress/Blogger ke built-in tools.

**Example:**
Ek blog post mein "best running shoes" ke topic par image lagate waqt:
1. Image ko **1000px width** tak resize karen (zyaada nahi).
2. **Alt text** mein "best running shoes for men 2024" likhein.
3. **Compress** karke size 100KB se kam karen (TinyPNG ya ShortPixel use karen).
4. **Lazy loading** enable karen taake page load time fast rahe.

**Practice:**
Apne blog ke kisi ek post ki sabse badi image ko:
- 800-1000px width tak resize karen (Canva ya Paint se).
- Alt text add karen jo post ke keyword se match kare.
- Compress karen taake size 150KB se kam ho.

**Mini Project:**
Ek **3-image collage** banayein (Canva ya Figma se) jo ek hi topic par ho (e.g., "blogging tips"). Uske baad:
- Sab images ko 700px width tak resize karen.
- Sabke alt text mein "blogging tips 2024" shamil karen.
- Collage ko post mein embed karen aur lazy loading check karen.

**Answer Key:**
resize, alt text, compress, lazy loading
