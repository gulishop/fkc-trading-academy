# Day 11 — **Blog Ke Liye Perfect Domain Name Kaise Choose Karein (2024 Guide)**

**Concept:**
Aaj hum seekhein ge ke ek professional aur SEO-friendly domain name kaise select karein jo yaad rahe aur brand value bana sake. Domain name aapki blog ki pehchan hai—isliye isko smartly choose karna zaroori hai. Avoid karna hai: complex spellings, numbers, hyphens, aur long names.

**Example:**
Agar aapka niche "Urdu cooking" hai, to:
❌ `BestUrduCooking123.com` (complex + number)
✅ `UrduKitchen.pk` (short, memorable, local TLD)

**Practice:**
Apne niche ke liye 3 domain name options likhein jo:
1. 2-3 words ke hon
2. Easy to spell/say hon
3. .com, .pk, .in mein available hon (use [Namecheap](https://www.namecheap.com/) ya [GoDaddy](https://www.godaddy.com/) check karne ke liye)

**Mini Project:**
Ek "Domain Name Brainstorming Sheet" banaein jismein:
- Aapka niche
- 5 potential domain names
- Availability check (✅/❌)
- Short reason (kyun choose kiya)

**Answer Key:**
short, memorable, .com/.pk, niche-relevant
