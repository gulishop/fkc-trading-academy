# Day 12 — **AI Se Viral Scripts Likhne Ke 3 Advanced Secrets**

**Concept:**
AI se script likhna ab beginner level se nikal kar advanced techniques tak pohoch gaya hai. Aaj hum 3 advanced secrets seekhenge jo aapke scripts ko viral banane mein madad karenge: **1) Hook Formula (Paathe ke pehle 5 seconds ko explosive banana)**, **2) AI Prompt Engineering (Script ko "human-like" aur engaging banana)**, **3) Emotional Trigger Points (Dard, Hasna, Ghabrana, ya Umeed ke moments add karna)**.

**Example:**
Ek AI tool (jaise Jasper ya Copy.ai) se script likhne ke liye prompt yeh use karen:
*"Write a YouTube script about 'How to earn $1000/month from YouTube automation' in Hindi. Start with a shocking hook: '90% log yeh galti karte hain jo aapki channel ko kabhi grow nahi hone deti!' Then add 3 emotional triggers: frustration (log fail hote hain), hope (AI tools se kaise hoga), and curiosity (is video ke last mein ek free template milega). Script 2-3 minutes ka ho, simple language mein."*

**Practice:**
Apne niche (e.g., "Make Money Online" ya "Tech Reviews") ke liye ek AI prompt likh kar script generate karo. Hook line aur 1 emotional trigger point zaroor add karna.

**Mini Project:**
Ek **1-minute script** likh kar AI se generate karo, usko CapCut mein voiceover aur background music ke saath edit karo, aur ek test upload karo (private/public nahi, sirf draft mein rakh kar dekh lo ki kaisa lagta hai).

**Answer Key:**
Shocking hook, emotional triggers, AI prompt engineering
