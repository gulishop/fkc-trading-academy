# Day 2 — AI Se YouTube Script Likhne Ka Step-by-Step Guide

**Concept:**
Aaj hum seekhenge ke AI tools (jaise ChatGPT, Jasper, ya Copy.ai) ka istemal karke professional YouTube scripts kaise likhe. AI se script likhte waqt inhe "human touch" dena zaroori hai—aisa content jo viewers ko engage kare. Hum AI ko prompt kaise dein, uske output ko improve karein, aur final script ko apne niche ke hisaab se customize karein.

**Example:**
1. **Prompt Design:** "Ek 5-minute YouTube script likho about 'How to Start a YouTube Channel in 2024' for beginners. Use simple Urdu/Hindi language, include 3 main points, and end with a call-to-action."
2. **AI Output:** AI ek draft dega—usko edit karke:
   - Introduction ko zyada engaging banayein (e.g., "Aaj main aapko bataunga ke YouTube channel kaise start kar sakte hain—bina kisi investment ke!")
   - Points ko real-life examples se samjhayein (e.g., "Jaise maine apne channel par 'Tech Tips' series shuru ki thi...")
   - CTA ko specific banayein (e.g., "Agar aapko yeh video pasand aaye to 'Subscribe' zaroor karen aur niche comment mein poochhein ke aapka niche kya hai.")

**Practice:**
Apne niche ke hisaab se ek YouTube video ka script likhein. AI tool (jaise ChatGPT) ka istemal karke ek 3-5 minute ke script ka draft taiyar karen. Uske baad usko apne style mein edit karen.

**Mini Project:**
Ek 1-minute ka "Hook" script likhein jo AI se generate karke usko apne voice ya style mein customize karen. Isse aapko pata chalega ke AI se content kaise modify karna hai.

**Answer Key:**
script draft, human touch editing, niche-specific examples, engaging CTA
