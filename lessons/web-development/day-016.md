# Day 16 — **JavaScript Events: User Interactions Ko Handle Karna**

**Concept:**
JavaScript events wo actions hain jo user website par perform karta hai (jaise click, hover, typing). Aaj hum seekhenge ki kaise `addEventListener()` use karke yeh events capture karein aur unke hisab se code run karain. Events web pages ko dynamic banati hain—jaise buttons click karne par content change karna ya forms submit karne par validation check karna.

**Example:**
Ek simple button banain jo click hone par ek alert show kare:
```html
<button id="alertBtn">Click Me!</button>
```
```javascript
const button = document.getElementById("alertBtn");
button.addEventListener("click", function() {
  alert("Button clicked!");
});
```
**Practice:**
Ek form banain jisme 2 fields hon (name aur email). Form submit hone par console.log mein "Form submitted!" print ho. (Hint: `submit` event use karo)

**Mini Project:**
**"Click Counter"**
- Ek button aur ek `<p>` element banain.
- Button click karne par `<p>` mein counter increase ho (e.g., "Clicks: 1", "Clicks: 2", etc.).
- Reset button bhi add karain jo counter ko 0 par le aaye.

**Answer Key:**
