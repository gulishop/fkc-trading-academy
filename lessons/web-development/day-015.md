# Day 15 — **JavaScript DOM Manipulation: Website Ko Dynamic Banana**

**Concept:**
JavaScript DOM (Document Object Model) se hum webpage ki structure ko dynamically change kar sakte hain. Isse hum buttons click karne par content change kar sakte hain, new elements add kar sakte hain, ya phir existing elements ko modify kar sakte hain. DOM manipulation se websites interactive aur dynamic ban jaati hain.

**Example:**
Ek simple webpage par ek button aur ek `<div>` hai. Button click karne par `<div>` ka color change ho jana chahiye:
```html
<button id="changeColor">Color Badlo</button>
<div id="box" style="width: 100px; height: 100px; background: red;"></div>
```
```javascript
document.getElementById("changeColor").addEventListener("click", function() {
  document.getElementById("box").style.background = "blue";
});
```

**Practice:**
Apne HTML file mein ek `<p>` tag aur ek button add karo. Button click karne par `<p>` tag ka text "Hello, World!" se "Assalamu Alaikum!" mein change ho jana chahiye.
