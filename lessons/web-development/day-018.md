# Day 18 — **Website Performance Optimization: Fast Loading Kaise Banaye**

**Concept:**
Aaj hum seekhenge ke website ko kaise fast load karaya ja sakta hai. Performance optimization se user experience improve hota hai, bounce rate kam hota hai, aur SEO bhi better hota hai. Hum compress karna, caching use karna, aur lazy loading jaise techniques par focus karenge.

**Example:**
1. **Images compress karna:**
   - Online tools jaise TinyPNG ya ImageOptim use karen.
   - HTML mein `<img src="compressed.jpg" loading="lazy" alt="...">` add karen (lazy loading ke liye).
2. **CSS aur JS ko minify karna:**
   - Tools jaise Terser (JS) ya CSSNano (CSS) use karen.
   - Minified files ko HTML mein `<link rel="stylesheet" href="styles.min.css">` jaise link karen.

**Practice:**
Apni ek existing website ya portfolio ke images ko compress karke, unhe lazy loading add karein. CSS/JS files ko minify karke check karein ke site ab fast load hoti hai.

**Mini Project:**
**"Fast Portfolio" Challenge**
- Apni portfolio website ke 3 performance issues fix karein (e.g., unoptimized images, render-blocking CSS/JS, no caching).
- Google PageSpeed Insights ya GTmetrix par test karein aur screenshot share karein.

**Answer Key:**
compress images, lazy loading, minify CSS/JS, caching headers
