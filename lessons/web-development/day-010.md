# Day 10 — **Advanced CSS: Custom Properties (Variables) aur Advanced Selectors**

**Concept:**
Aaj hum **CSS Custom Properties** (variables) aur **advanced selectors** (like `:nth-child`, `:not()`, attribute selectors) seekhenge. Variables se styling ko reusable banaya ja sakta hai, jabke advanced selectors se specific elements ko target karna asaan ho jata hai. Yeh performance bhi improve karta hai aur code maintain karne mein bhi help karta hai.

**Example:**
1. **Variables:**
   ```css
   :root {
     --primary-color: #3498db;
     --spacing: 1rem;
   }
   .button {
     background: var(--primary-color);
     padding: var(--spacing);
   }
   ```
2. **Advanced Selector:**
   ```css
   /* Every odd list item */
   li:nth-child(odd) { background: #f0f0f0; }

   /* All inputs except password */
   input:not([type="password"]) { border: 1px solid #ccc; }
   ```

**Practice:**
Apne **portfolio website** ke liye ek CSS file mein 3 custom variables define karo (`--main-bg`, `--text-color`, `--accent-color`). In variables ko navbar, buttons, aur footer mein use karo.

**Mini Project:**
Ek **dynamic theme switcher** banao jo ek button click par `--main-bg` aur `--text-color` change kar de (e.g., light/dark mode).

**Answer Key:**
root variables, :nth-child, :not(), reusable styling
