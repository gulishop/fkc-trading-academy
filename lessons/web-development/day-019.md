# Day 19 — **Introduction to APIs: Fetching Data from External Sources**

**Concept:**
APIs (Application Programming Interfaces) allow websites to fetch data from external services like weather apps, news sites, or databases. Today, we’ll learn how to use JavaScript’s `fetch()` to get data from a public API (e.g., JSONPlaceholder for fake posts) and display it on a webpage. APIs are crucial for dynamic content without manual updates.

**Example:**
1. **API Endpoint:** Use `https://jsonplaceholder.typicode.com/posts` (returns 100 fake blog posts).
2. **Fetch Data:**
   ```javascript
   fetch('https://jsonplaceholder.typicode.com/posts')
     .then(response => response.json())
     .then(data => {
       data.slice(0, 5).forEach(post => {
         document.body.innerHTML += `<div><h3>${post.title}</h3><p>${post.body}</p></div>`;
       });
     });
   ```
3. **Error Handling:** Add `.catch(error => console.error('Error:', error))`.
