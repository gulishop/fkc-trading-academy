# Day 14 — **CSS Frameworks: Bootstrap aur Tailwind CSS Se Fast Development**

**Concept:**
CSS frameworks jaise Bootstrap aur Tailwind CSS pre-built components aur utilities provide karte hain jo responsive aur modern websites banane ko 10x fast kar dete hain. Inke grids, buttons, cards aur utility classes (margins, padding, colors) ke zariye tum bina zyada CSS likhe hi professional-looking websites bana sakte ho.

**Example:**
Bootstrap ka grid system:
```html
<div class="container">
  <div class="row">
    <div class="col-md-6">Left Side (6 columns on medium screens)</div>
    <div class="col-md-6">Right Side (6 columns on medium screens)</div>
  </div>
</div>
```
Tailwind CSS ka utility class example:
```html
<button class="bg-blue-500 hover:bg-blue-700 text-white font-bold py-2 px-4 rounded">
  Click Me
</button>
```

**Practice:**
Ek simple 3-column layout banane ke liye Bootstrap ya Tailwind CSS ka istemal karo. Har column mein ek heading aur paragraph ho. Mobile par yeh 1 column, tablet par 2, aur desktop par 3 columns mein show hona chahiye.

**Mini Project:**
**"Restaurant Menu Page"** — Bootstrap ya Tailwind CSS use karke ek responsive menu page banao jisme:
- Header (logo + navigation)
- 3-4 food items (card format mein)
- Footer (contact info)
Sab responsive ho (mobile, tablet, desktop par sahi dikhe).

**Answer Key:**
Bootstrap grid, col-md-4, Tailwind grid-cols-1 md:grid-cols-3, card, container
