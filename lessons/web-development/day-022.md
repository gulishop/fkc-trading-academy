# Day 22 — **CSS Variables aur Custom Properties: Reusable Styles Banana**

**Concept:**
CSS variables (ya custom properties) aapko reusable values define karne dete hain jo poore project mein use ho sakte hain. Inse colors, fonts, spacing, aur even complex calculations ko centrally manage kar sakte hain. Browser support strong hai, aur dynamic changes bhi easily apply ki ja sakti hain JavaScript se.

**Example:**
```css
:root {
  --primary-color: #3498db;
  --spacing-unit: 1rem;
  --font-main: 'Arial', sans-serif;
}

.button {
  background: var(--primary-color);
  padding: var(--spacing-unit);
  font-family: var(--font-main);
}
```
Ab agar `--primary-color` change karni ho to sirf `:root` mein update karo, saare elements automatically reflect honge.

**Practice:**
Apne existing project mein 3 CSS variables define karo: `--main-bg`, `--text-color`, aur `--border-radius`. Inhe `<body>` aur `<button>` elements par apply karo.

**Mini Project:**
Ek simple "Theme Switcher" banaye jo 2 buttons se `--main-bg` aur `--text-color` ko toggle kare (JavaScript se). Pehle light theme, phir dark theme ka button add karo.

**Answer Key:**
`:root, --main-bg, --text-color, --border-radius, JavaScript getComputedStyle`
