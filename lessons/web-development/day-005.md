# Day 5 — JavaScript Functions aur Events: Interactive Web Banaana

**Concept:**
JavaScript functions reusable code blocks hain jo tasks perform karte hain. Events (jaise click, submit) use functions ko trigger karte hain. Aaj hum seekhenge kaise functions banaye jaate hain aur unhe HTML elements ke saath connect karke interactive web pages banaye jaate hain.

**Example:**
```javascript
function greet(name) {
  console.log("Hello, " + name + "!");
}
greet("Ali"); // Output: "Hello, Ali!"

// Event listener add karna
document.getElementById("myButton").addEventListener("click", function() {
  alert("Button clicked!");
});
```

**Practice:**
Ek button banaye `<button id="colorBtn">Change Color</button>` aur uske click event par ek function run karaye jo `<p>` tag ki text color change kar de (e.g., red).

**Mini Project:**
**"Click Counter"** – Ek button aur ek `<p>` tag banaye jo har click par counter badha de (e.g., "Clicks: 1", "Clicks: 2", etc.).

button click handler, counter variable, textContent update
