# Day 9 — **Website Accessibility Basics: Sabke Liye Inclusive Web Banana**

**Concept:**
Aaj hum seekhenge ke ek accessible website kaise banayein taake visually impaired, motor disabilities, ya slow internet walay users bhi aapki website ko aasani se use kar saken. Accessibility sirf "good practice" nahi balki kayi countries mein legally required bhi hai. Hum focus karenge: semantic HTML, ARIA labels, keyboard navigation, aur contrast ratios.

**Example:**
Ek simple form mein `<label>` ka istemal karna:
```html
<label for="email">Email Address:</label>
<input type="email" id="email" name="email">
```
Yeh screen readers ko batata hai ke "Email Address" input field ka label hai. Bina `<label>` ke, screen reader user ko pata nahi chalta ke yeh kya field hai.

**Practice:**
Apne existing project ke kisi form ya navigation menu mein:
1. Sabhi `<input>` elements ke liye `<label>` add karo (agar nahi hain).
2. `<button>` elements mein `aria-label` attribute add karo agar text clear nahi hai (e.g., `<button aria-label="Close menu">X</button>`).

**Mini Project:**
**"Accessible Portfolio Card"** banayein:
- Ek card design karo jisme:
  - Heading `<h2>` se ho (not `<div>`)
  - Image ke liye `<img alt="Description">` (alt text meaningful ho)
  - "Read More" button ke liye `aria-label="Read more about [topic]"`
  - Keyboard se tab karne par focus visible ho (CSS: `button:focus { outline: 2px solid blue; }`)

**Answer Key:**
semantic HTML, aria-labels, keyboard navigation, high contrast
