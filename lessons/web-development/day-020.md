# Day 20 — **Introduction to Web Accessibility: Making Websites Inclusive**

**Concept:**
Web accessibility ensures websites work for everyone, including people with disabilities (visual, motor, cognitive). Learn WCAG guidelines, ARIA roles, keyboard navigation, and semantic HTML to create inclusive sites. Even small changes (like alt text, proper contrast) make a big difference.

**Example:**
1. Add `alt="A red apple on a wooden table"` to `<img>` for screen readers.
2. Use `<button>` instead of `<div>` for clickable elements (keyboard accessible).
3. Ensure color contrast (e.g., dark text on light background).

**Practice:**
Take your portfolio website and:
- Add `alt` text to all images.
- Test keyboard navigation (Tab/Enter should work everywhere).
- Use semantic tags (`<header>`, `<nav>`, `<main>`).

**Mini Project:**
Create a simple accessible contact form with:
- Labels for all inputs (`<label for="email">`).
- Error messages (e.g., "Please enter a valid email").
- Focus styles for keyboard users (CSS `:focus`).

**Answer Key:**
alt text, semantic HTML, keyboard navigation, ARIA labels
