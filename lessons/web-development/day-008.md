# Day 8 — **Website Performance Optimization: Fast aur Efficient Websites Banana**

**Concept:**
Aaj hum seekhenge ke apni website ko kaise fast banayein. Performance optimization se loading time kam hota hai, user experience improve hota hai, aur search engines (jaise Google) bhi website ko zyada rank karte hain. Hum caching, image optimization, lazy loading, aur code minification jaise techniques cover karenge.

**Example:**
1. **Images optimize karna:** `img` tag mein `loading="lazy"` add karke lazy loading enable karo. Example:
   ```html
   <img src="image.jpg" alt="Example" loading="lazy">
   ```
2. **CSS aur JS minify karna:** Unnecessary spaces aur comments remove karke files ka size kam karo. Online tools jaise [CSS Minifier](https://cssminifier.com/) ya [JS Minifier](https://javascript-minifier.com/) use kar sakte ho.
3. **Browser caching enable karna:** Server par `Cache-Control` header set karke repeat visitors ke liye loading time reduce karo.

**Practice:**
Apni portfolio website ya kisi bhi existing project mein:
1. Sabhi images mein `loading="lazy"` add karo.
2. Ek CSS file ko minify karke original ke saath replace karo.
3. Google PageSpeed Insights ([link](https://pagespeed.web.dev/)) par apni website test karo aur suggestions follow karo.

**Mini Project:**
**"Fast Portfolio"** – Apni portfolio website ko optimize karo taake:
- Google PageSpeed Insights par score 90+ ho.
- Mobile aur desktop dono par fast load ho.
- Sabhi images optimized ho (WebP format use kar sakte ho).

**Answer Key:**
lazy loading, minification, caching, WebP format
