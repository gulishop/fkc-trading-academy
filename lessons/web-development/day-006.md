# Day 6 — **User Input Validation: Clean aur Secure Data Lekhna**

**Concept:**
Aaj hum seekhenge ke user se input lene ke baad usko validate kaise karna hai — taake galat ya incomplete data website mein na chale jaye. JavaScript aur HTML attributes (jaise `required`, `pattern`) ka istemal karke hum yeh ensure kar sakte hain ke user ne sahi format mein data diya hai (e.g., email `@` ke saath, phone number sirf numbers).

**Example:**
Ek simple **contact form** banate hain jisme:
1. Email field (`type="email"`) — browser khud `@` check karega.
2. Phone number (`type="tel"` + `pattern="[0-9]{10}"`) — sirf 10 digits allow honge.
3. JavaScript se `onsubmit` event par check karo ke sab fields filled hain.

```html
<form id="contactForm">
  <input type="email" name="email" required>
  <input type="tel" name="phone" pattern="[0-9]{10}" required>
  <button type="submit">Bhejo</button>
</form>

<script>
  document.getElementById("contactForm").onsubmit = function(e) {
    if (!this.checkValidity()) {
      e.preventDefault();
      alert("Please fill all fields correctly!");
    }
  };
</script>
```

**Practice:**
Ek **signup form** banaye jisme:
- Username (min 5 characters, sirf letters/numbers)
- Password (min 8 characters, 1 uppercase, 1 number)
- Confirm Password (password se match karna hai)
- `required` attribute use karna hai.

**Mini Project:**
**"Restaurant Order Form"** banaye:
- User se naam, email, dish select (dropdown), quantity (number), aur special instructions (textarea) le.
- Form submit hone se pehle check karo ke:
  - Email valid hai (`@` aur `.` hai)
  - Quantity 1 se zyada hai
  - Dish select kiya gaya hai
- Agar koi error ho to alert show karo, warna form submit ho jaye.

**Answer Key:**
username: letters/numbers, min 5, password: 8+ chars, 1 uppercase+number, confirm password match, email: @ aur .
