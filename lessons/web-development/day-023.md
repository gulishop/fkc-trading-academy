# Day 23 — **Modern CSS: Container Queries aur Scoped Styles**

**Concept:**
Aaj hum **Container Queries** aur **Scoped Styles** seekhenge — yeh CSS ke advanced features hain jo responsive design ko aur behtar banate hain. **Container Queries** se hum kisi parent container ke size ke hisaab se styles apply kar sakte hain (e.g., ek card ka layout desktop par alag, mobile par alag ho sakta hai). **Scoped Styles** (CSS Scoping) se hum styles ko sirf specific components tak limit kar sakte hain, taaki global conflicts na ho.

**Example:**
1. **Container Query ka istemal:**
   ```css
   .card-container {
     container-type: inline-size; /* Container query enable karne ke liye */
   }
   @container (max-width: 600px) {
     .card {
       flex-direction: column;
     }
   }
   ```
   ```html
   <div class="card-container">
     <div class="card">...</div>
   </div>
   ```
   Yahan `.card` ka layout parent container ki width par depend karega.

2. **Scoped Styles ka istemal:**
   ```css
   @scope (.card) to (.card-content) {
     .card-content { padding: 1rem; }
   }
   ```
   Yeh styles sirf `.card` ke andar `.card-content` tak apply honge.

**Practice:**
Ek simple layout banayein jismein 3 cards hain. Har card ke andar ek heading aur paragraph ho. **Container Query** ka istemal karke desktop par cards ko `row` mein aur mobile par `column` mein display karain.

**Mini Project:**
**"Responsive Card Gallery"**
- 3 cards banayein (heading + paragraph + button).
- Desktop par cards `display: flex; flex-wrap: wrap;` se arrange hon.
- Mobile par (width < 600px) har card `width: 100%;` ho jaye.
- Har card ka background color aur padding container ke size par depend kare (Container Query se).

**Answer Key:** cards, flex-direction: column, container-type: inline-size, @container
