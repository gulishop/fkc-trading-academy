# Day 11 — **Meta Tags aur SEO Basics: Apni Website Ko Google Par Dikhana**

**Concept:**
Meta tags HTML ke `<head>` section mein hoti hain jo search engines (jaise Google) ko batati hain ke aapki website kya hai. SEO (Search Engine Optimization) ka matlab hai apni website ko search results mein upar lane ke liye techniques use karna. Meta tags aur SEO ke basics se aapki website zyada visible aur professional dikhegi.

**Example:**
1. **Meta Tags ka Structure:**
```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Meri portfolio website jahan main apne web development projects dikhata hoon.">
  <meta name="keywords" content="web development, portfolio, HTML, CSS">
  <title>Mera Portfolio | Web Developer</title>
</head>
```
2. **SEO ka Basic Step:**
- Apni website ka `title` aur `description` meta tags mein unique aur relevant rakho.
- `keywords` meta tag ab kam use hota hai, lekin `description` Google search results mein show hoti hai.

**Practice:**
Apni portfolio website ke `<head>` section mein yeh meta tags add karo:
- `description` mein apne portfolio ka 1-2 line ka introduction likho.
- `title` ko "Mera Portfolio | [Apna Naam]" format mein change karo.

**Mini Project:**
Ek **SEO-friendly blog post** banayein:
1. Ek HTML file banayein (`blog.html`).
2. Uske `<head>` mein meta tags add karo (title, description, viewport).
3. Page par ek heading (`<h1>`) aur 2-3 paragraphs likhein.
4. Google par "site:apni-website.com" search karke check karo ke meta tags kaise dikhte hain.

**Answer Key:**
title tag, description meta, viewport meta, SEO-friendly content
