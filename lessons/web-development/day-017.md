# Day 17 — **JavaScript: Local Storage aur Session Storage – User Data Save Karna**

**Concept:**
Aaj hum JavaScript ke `localStorage` aur `sessionStorage` ko seekhenge. Ye storage methods browser mein key-value pairs ke form mein data save karte hain (jaise user preferences, login status, ya form data). `localStorage` permanently save hota hai jab tak manually delete na kiya jaye, jabke `sessionStorage` sirf tab tak rahta hai jab tak browser tab khula ho.

**Example:**
1. **localStorage mein data save karna:**
   ```javascript
   localStorage.setItem('username', 'Ali123');
   ```
2. **Data retrieve karna:**
   ```javascript
   const user = localStorage.getItem('username');
   console.log(user); // Output: "Ali123"
   ```
3. **Data remove karna:**
   ```javascript
   localStorage.removeItem('username');
   ```

**Practice:**
Ek simple form banayein jisme user apna naam aur email enter kare. Submit karne par ye data `localStorage` mein save ho jaye. Page refresh hone par bhi data display ho.

**Mini Project:**
**"Todo List App with Persistence"**
- Ek todo list banayein jisme:
  - User naye tasks add kar sake.
  - Tasks `localStorage` mein save hon.
  - Page refresh hone par tasks wapas show hon.
- Hint: `localStorage.setItem('tasks', JSON.stringify(tasks))` aur `JSON.parse(localStorage.getItem('tasks'))` use karna.

**Answer Key:**
saveItem, getItem, removeItem, JSON.stringify
