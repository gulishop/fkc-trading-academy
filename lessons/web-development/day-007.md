# Day 7 — **CSS Animations aur Transitions: Interactive Effects Banana**

**Concept:**
CSS animations aur transitions se aap apne buttons, menus, ya kisi bhi element ko dynamic banate hain. Transitions se smooth changes (jaise color change ya size shift) hoti hain jab koi property change hoti hai, jabki animations se aap complex effects (jaise spinning, fading, ya bouncing) bana sakte hain. Yeh user experience ko improve karta hai aur website ko zyada engaging banata hai.

**Example:**
Ek button ko hover karne par color change karne ka step-by-step:
```css
.button {
  background: blue;
  transition: background 0.3s ease;
}
.button:hover {
  background: red;
}
```
Ab agar aap `button` element ko hover karenge, toh background color 0.3 seconds mein smoothly blue se red ho jayega.

**Practice:**
Apne ek existing button ko select karke uspar `transition` property add karo taake uska `width` 0.5s mein badle jab mouse uspar hover kare. CSS aur HTML donon mein changes karne hain.

**Mini Project:**
Ek "Click Me" button banao jo:
1. Normal state mein blue hai.
2. Hover par green ho jaye.
3. Click karne par 1 second ke liye red ho jaye, phir wapas blue ho jaye.
4. Transition smooth ho (0.3s).

**Answer Key:**
transition: background 0.3s ease, button:hover background green, button:active background red
