# Day 13 — **JavaScript Basics: Variables, Functions aur Events**

**Concept:**
JavaScript (JS) ek programming language hai jo websites ko "live" banati hai. Is se hum buttons click karne par kuch hota hai, forms validate kar sakte hain, aur real-time updates show kar sakte hain. Aaj hum variables (data store karne ke liye), functions (code ko reusable banane ke liye), aur events (user actions jaise click, scroll) par focus karenge.

**Example:**
Ek simple button banayein jo click karne par ek alert show kare:
```html
<button id="myButton">Click Me!</button>
```
```javascript
const button = document.getElementById("myButton");
button.addEventListener("click", function() {
  alert("Button clicked!");
});
```
Yahan `const` ek variable hai jo button ko store karta hai, `addEventListener` ek event handle karta hai, aur `function()` ek reusable block hai jo click hone par run hota hai.

**Practice:**
Ek simple calculator banayein:
1. Do input fields (`<input type="number">`) aur ek button add karein.
2. Button click par do numbers ko add karke result `<p>` mein display karein.
3. Hint: `document.getElementById("result").textContent = num1 + num2;`
