# Day 24 — **Introduction to Backend Basics: APIs aur Server-Side Programming**

**Concept:**
Aaj hum backend development ke basics seekhenge. Backend server par chalta hai jo frontend (HTML/CSS/JS) se requests accept karta hai aur responses bhejta hai. APIs (Application Programming Interfaces) backend aur frontend ke beech communication ka bridge hoti hain. Hum `Node.js` aur `Express.js` ka istemal karke ek simple API banayenge jo data send/recieve karegi.

**Example:**
Ek simple Express server banane ke steps:
1. Terminal mein `npm init -y` aur `npm install express` run karein.
2. `server.js` file banayein:
   ```javascript
   const express = require('express');
   const app = express();
   app.use(express.json());

   app.get('/api/greet', (req, res) => {
     res.json({ message: "Hello, World!" });
   });

   app.listen(3000, () => {
     console.log("Server running on http://localhost:3000");
   });
   ```
3. Terminal mein `node server.js` run karein aur browser mein `http://localhost:3000/api/greet` open karein.

**Practice:**
Apne Express server mein ek `/api/time` endpoint add karein jo current time return kare. (Hint: `new Date()` ka istemal karein)

**Mini Project:**
