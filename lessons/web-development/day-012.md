# Day 12 — **CSS Transitions aur Animations: Smooth aur Interactive Effects Banana**

**Concept:**
CSS transitions aur animations se hum elements ko smoothly change kar sakte hain (jaise color, size, position). Transitions ek property se judi hoti hain (e.g., `transition: all 0.3s ease;`), jabki animations `@keyframes` ke zariye multiple steps define karti hain. Yeh user experience ko improve karte hain aur website ko zyada interactive banate hain.

**Example:**
Ek button ka background color hover par 0.5s mein badalne ke liye:
```css
.button {
  background: blue;
  transition: background 0.5s ease;
}
.button:hover {
  background: red;
}
```
Ek simple animation (fade-in) ke liye:
```css
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
.box {
  animation: fadeIn 1s ease-in;
}
```

**Practice:**
Apne ek existing HTML element (jaise `<div>` ya `<button>`) par hover par scale 1.2 tak badalne ke liye CSS transition use karo. `transition` property ka use karna hai.

**Mini Project:**
Ek **loading spinner** banana hai jo 2s tak rotate ho aur phir disappear ho. Iske liye:
1. Ek `<div>` banana hai spinner ke liye.
2. `@keyframes` use karke usko rotate karna hai.
3. Animation ko `animation` property se apply karna hai (2s duration, `linear` timing).

**Answer Key:**
transition: all 0.3s ease, hover: scale(1.2), @keyframes spin, animation: spin 2s linear
