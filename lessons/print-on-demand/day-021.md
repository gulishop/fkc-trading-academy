# Day 21 — **AI Tools Se Designs Ko Fast & Professional Banayein**

**Concept:**
AI tools (jaise MidJourney, DALL·E, Canva AI) se designs ko 10x faster banaya ja sakta hai. In tools se unique art, text styles aur mockups generate kiye ja sakte hain jo manually karne mein bohat time lagta hai. AI se consistency bhi maintain hoti hai aur trends ke hisaab se designs update kiye ja sakte hain.

**Example:**
1. **MidJourney se design banayein:**
   - Prompt likhein: *"A minimalist t-shirt design with a mountain silhouette, sunset colors, vector style, trending on Etsy"*
   - AI 4-5 variations generate karega. Apne hisaab se best select karke Canva mein edit karein.
2. **Canva AI se text style add karein:**
   - "Text to Image" feature use karein aur apne text ko stylize karne ka prompt dein.

**Practice:**
Apne niche (jaise pets, fitness, motivational quotes) ke liye **1 AI-generated design** banayein aur Canva mein usko finalize karein.

**Mini Project:**
Ek **AI se banaye gaye 3 designs ka collection** banayein (ek t-shirt, ek mug, ek poster) aur unhe apne mockup tools (Printful/Placeit) par test karein.

**Answer Key:**
AI prompt, Canva edit, mockup test, design variations
