# Day 19 — **Customer Service Kaise Dein? (Returns, Reviews & Trust Build Karna)**

**Concept:**
Print on demand mein customer service sirf complaints handle karna nahi hai—yeh trust build karne aur repeat customers paalne ka zariya hai. Returns, refunds, aur reviews ka proactively manage karna aapki brand ki credibility badhata hai. Agar customer ko koi issue ho aur aap usko professionally solve kar dein, toh wo dobara khareedne ke liye ready ho jata hai.

**Example:**
Ek customer ko T-shirt pehne ke pata chalta hai ki size mismatch hai. Aap usko:
1. **Clear return policy** batayein (e.g., "30 days return, no questions asked").
2. **Easy return process** provide karein (prepaid return label ya simple steps).
3. **Quick refund** dein (24-48 hours mein).
4. **Follow-up email** bhej kar puchein ki wo dobara khareedna pasand karega ya nahi.

**Practice:**
Apne store ki return policy likhein (3-5 lines mein). Include karein:
- Return ki time limit (e.g., "30 days").
- Kaunse items return ho sakte hain (e.g., "sabhi items, packaging intact").
- Refund process (e.g., "automatic refund after item receive").

**Mini Project:**
Ek **customer service email template** banaein jo aap use karenge jab koi complaint kare. Format:
1. **Subject:** "Your Concern is Our Priority – [Order #]"
2. **Body:** Empathy show karein + solution propose karein + next steps batayein.
3. **Tone:** Polite, professional, aur solution-oriented.

**Answer Key:**
return policy, refund process, customer trust, repeat sales
