# Day 4 — **AI Tools Se Designs Banane Ka Advanced Guide**

**Concept:**
AI tools (jaise MidJourney, DALL·E, Leonardo.ai) se designs banane ka matlab hai ke aap ke concepts ko real-time images mein convert kar sakte hain. Yeh tools beginner-friendly hain aur trends 2024 ke hisaab se best designs generate karne mein madad karte hain. Canva ke AI features (jaise Magic Design) bhi yahan kaam aate hain.

**Example:**
1. **Prompt Likhna:** "A minimalist t-shirt design with a mountain silhouette in dark blue and white, flat lay style, high resolution"
2. **AI Tool Use:** MidJourney mein `/imagine prompt: [apna prompt]` likhein.
3. **Variations Select Karein:** 4-6 options mein se best choose karein.
4. **Edit Karein:** Canva ya Photoshop se text add karein (e.g., "Explore the Peaks").

**Practice:**
Apne niche (e.g., fitness, travel) ka ek AI-generated design banayein. Prompt ko 3 baar modify karein aur best result save karein.

**Mini Project:**
Ek **AI-generated t-shirt design** banayein aur usko Printful ke mockup generator mein upload karein. Design ka naam rakhein: "AI_Trend_[Niche]_[Date]".

**Answer Key:**
AI prompt, Canva/MidJourney, mockup test, design name
