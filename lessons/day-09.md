# Day 9 — While Loop

- **Concept:** Jab tak condition sach ho, loop chalta rahe
- **Example:**
  ```python
  count = 1
  while count <= 5:
      print("Count:", count)
      count += 1
  ```
- **Practice:** 10 se 1 tak ulta count karwayen
- **Mini Project:** "Countdown Timer" (number se 0 tak count karke "Khatam!" print kare)
