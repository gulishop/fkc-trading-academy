# Day 4 — AI Video Tools: AI Se Professional Videos Banana Seekhiye

**Concept:**
AI video tools se aap text se video, existing clips ko edit karne, ya even realistic avatars banane ka kaam kar sakte hain. Yeh tools beginners ke liye bhi easy hain aur advanced features bhi offer karte hain. Aaj hum top 3 tools (Pictory, Synthesia, Runway ML) ke basics seekhenge.

**Example:**
1. **Pictory (Text-to-Video):**
   - Apna script type karo ya paste karo.
   - AI automatically relevant clips, background music, aur captions add karega.
   - "AI is changing business" likh kar dekhiye — 1 minute ki video bana ke milegi.

2. **Synthesia (AI Avatars):**
   - Ek virtual host select karo (e.g., "Sarah").
   - Apna script type karo — AI host ki voice aur lipsync karegi.
   - Business training videos ya presentations ke liye perfect.

**Practice:**
Pictory par jayein, ek 3-line ka script type karin (e.g., "Hello! Main AI hoon. Aaj hum video banayenge."), aur ek 30-second video generate karin.

**Mini Project:**
Ek 1-minute ka "AI Tools Introduction" video banayein — script likhein, Pictory/Synthesia se generate karin, aur YouTube par upload karne ke liye taiyaar karin.

**Answer Key:**
script type, AI clips select, video download
