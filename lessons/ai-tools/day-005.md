# Day 5 — AI Se Workflows Automate Karna: No-Code Tools (Zapier/Make) Se

**Concept:**
Aaj hum AI-powered no-code tools (Zapier/Make) se apne daily workflows automate karna seekhenge. Yeh tools APIs connect karke different apps ke beech data flow banate hain bina coding ke. Zaroori hai ke aapko pata ho ke kaunse apps ke beech automation possible hai (jaise Gmail → Google Sheets, WhatsApp → Notion, etc.).

**Example:**
Ek simple automation: Jab koi aapko Gmail par email bhejega, uska sender name aur subject automatically Google Sheets mein add ho jaye.
1. Zapier mein "Gmail" trigger select karo.
2. "New Email" event choose karo.
3. Action app mein "Google Sheets" select karo.
4. "Add Row" action choose karo aur spreadsheet details fill karo.
5. Test karo aur turn on kar do.

**Practice:**
Apne Gmail inbox se latest 5 emails ke sender names aur subjects ko Google Sheets mein add karne ka automation create karo (Zapier/Make mein).

**Mini Project:**
Ek automation banaye jo jab aapko WhatsApp par koi message bhejega, uska text automatically Notion mein ek new page banaye. (Hint: WhatsApp Business API ya unofficial tools use karne honge.)

**Answer Key:**
Gmail trigger, Google Sheets add row, sender name, email subject
