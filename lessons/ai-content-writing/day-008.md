# Day 8 — **Freelance Platforms Se Gig Kaise Jeeto: Upwork & Fiverr Mastery**

**Concept:**
Freelance platforms jaise Upwork aur Fiverr par content writing gigs jeetne ke liye profile optimization, proposal writing, aur pricing strategy samajhna zaroori hai. AI tools se bhi help li ja sakti hai, lekin originality aur client ke needs ko samajh kar hi proposal bhejna chahiye.

**Example:**
1. **Profile Setup:** Upwork par "Content Writer" title ke saath "SEO-optimized blog posts & engaging social captions" description add karo.
2. **Proposal:** Client ke project description ko padh kar uske keywords ko apne proposal mein repeat karo (e.g., "You need 10 SEO blogs? I’ll write them with keyword density under 2%").
3. **Pricing:** Niche ke hisab se rates set karo—new writers ke liye $0.03-0.05/word (Upwork) ya $5-10 per 500 words (Fiverr).

**Practice:**
Apne Upwork/Fiverr profile ka ek screenshot le kar uske 3 strong points likho jo gig jeetne mein help kar sakte hain.

**Mini Project:**
Ek Upwork proposal draft karo (150-200 words) kisi fake client ke project ke liye (e.g., "5 product description for e-commerce site").

**Answer Key:**
SEO keywords, client needs, competitive pricing, strong CTA
