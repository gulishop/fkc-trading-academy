# Day 9 — **Algorithmic Trading: Computer Se Trading Kaise Karein?**

**Concept:**
Algorithmic trading mein computer programs (algorithms) use karke automated buy/sell orders lagaye jate hain. Isse speed, accuracy, aur emotion-free trading hoti hai. Beginners ko pehle manual trading se familiar hona chahiye, lekin yeh advanced technique hai jo long-term efficiency badhati hai.

**Example:**
Ek simple moving average crossover strategy: Agar 50-day MA 200-day MA se upar chala jaye ("Golden Cross"), to buy signal generate hota hai. Python mein `ta-lib` library use karke yeh code likha ja sakta hai:
```python
import talib
import pandas as pd

data = pd.read_csv('stock_data.csv')
data['MA50'] = talib.SMA(data['Close'], timeperiod=50)
data['MA200'] = talib.SMA(data['Close'], timeperiod=200)
buy_signal = data['MA50'] > data['MA200']
```
