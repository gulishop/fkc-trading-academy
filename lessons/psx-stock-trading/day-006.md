# Day 6 — **Trading Orders: Limit vs Market vs Stop-Loss**

**Concept:**
Trading orders hei woh commands jo aap broker ko dete hain ke shares khareedne ya bechne hain. **Market order** (turant khareed/bech de), **Limit order** (apna desired price set karo), aur **Stop-Loss order** (nuksaan limit set karo) sabse zyada use hote hain. Har order ka apna faida hai—samajhna zaroori hai ke kab kya use karna hai.

**Example:**
1. **Market Order:** Agar aapko 100 shares **turant** khareedne hain, to broker ko market order do. Broker current price (e.g., Rs. 100/share) par 100 shares khareed lega.
2. **Limit Order:** Agar aap Rs. 95/share par khareedna chahte hain (current price Rs. 100 hai), to limit order set karo. Jab price Rs. 95 aaye, order execute hoga.
3. **Stop-Loss Order:** Agar aap Rs. 90/share se zyada nuksaan nahi uthana chahte, to stop-loss Rs. 90 par set karo. Agar price Rs. 90 se neeche girta hai, order automatically execute ho jata hai.

**Practice:**
Apne broker ke app ya website par jao aur:
- **1 market order** (kisi bhi share ka 1 share khareedne ke liye).
- **1 limit order** (apna desired price set karke).
- **1 stop-loss order** (kisi share ka price set karke).

**Mini Project:**
Ek **trading plan** banayein:
1. 3 shares select karo (e.g., OGDC, MCB, ENGRO).
2. Har share ke liye **limit order** set karo (apna desired price likho).
3. Har share ke liye **stop-loss** bhi set karo (nuksaan ki limit).
4. 1 week tak track karo ke orders execute hue ya nahi.

**Answer Key:**
Market order, limit order, stop-loss, execution price
