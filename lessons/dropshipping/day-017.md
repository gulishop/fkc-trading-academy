# Day 17 — **COD Orders Ko Secure Karein: Pakistan Mein Fraud Se Kaise Bachain**

**Concept:**
COD (Cash on Delivery) Pakistan mein dropshipping ka common method hai, lekin fraud orders (fake addresses, chargebacks) ka risk bhi zyada hai. Aaj seekhein ke COD orders ko kaise verify karein, high-risk areas ko identify karein, aur fraud se kaise bachain—bina sales ko affect karein.

**Example:**
1. **Address Verification:** Agar order Lahore ke "Model Town" se hai lekin courier company ka record show karta hai ke woh area "closed" hai, toh order reject kar dein.
2. **Phone Number Check:** Agar customer ka number "0300-1234567" hai lekin Google par search karne par woh number kisi scam report se match karta hai, toh order cancel kar dein.
3. **Prepaid COD:** Agar order value Rs. 5,000+ hai, toh customer ko "Prepaid COD" ka option dein (e.g., "JazzCash se advance payment karne par Rs. 200 discount").

**Practice:**
Apne store ke last 5 COD orders ko check karain. Har order ke liye yeh verify karein:
- Kya shipping address valid hai? (Google Maps par check karein)
- Kya customer ka number kisi fraud report se match karta hai? (Truecaller ya local forums check karein)

**Mini Project:**
Ek simple Excel sheet banaein jismein har COD order ke liye yeh columns hon:
1. Order ID
2. Customer Name
3. Shipping Address (valid/invalid)
4. Phone Number (fraud/clean)
5. Order Value (Rs.)
6. Decision (Accept/Reject/Prepaid COD)

**Answer Key:**
address verification, phone number check, prepaid COD, fraud detection
