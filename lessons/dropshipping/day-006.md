# Day 6 — **Facebook Ads Se Zero-to-Hero Traffic: Budget Se Le Kar Creatives Tak**

**Concept:**
Facebook Ads dropshipping ka backbone hai—lekin *wrong* approach se paise barbad karne ka zariya bhi. Aaj seekhenge ki kaise **low budget se start karke**, **high ROAS** wale ads banayein. Key focus hai: **Audience targeting (lookalike + interest-based), ad creatives (hook + CTA), aur budget optimization** (kaise $5/day se $50/day tak scale karna hai).

**Example:**
Ek *fitness supplement* product ka ad banate hain:
1. **Hook:** "30 Days Mein 10KG Kam Karne Ka Secret? 👀" (emoji + curiosity)
2. **Video Creative:** 5-second clip jisme customer apne aap ko mirror mein dekh raha hai (before/after nahi, *feeling* show karo).
3. **CTA:** "Abhi Order Karen—Stock Khali Hai!" (urgency + scarcity).
4. **Targeting:** "Weight Loss" interest + "Fitness Influencers" lookalike audience (1-2% overlap).

**Practice:**
Apne *current* product ka **3 ad creatives** banayein (1 image, 1 video, 1 carousel). Har creative mein **hook + CTA** zaroor add karein. Facebook Ads Manager mein ja kar **"Audience"** section mein apne product ke **3 interest-based audiences** likhein (e.g., "Yoga Enthusiasts," "Gym Beginners," "Home Workout").

**Mini Project:**
Ek **$5/day budget** wala ad set create karein. Steps:
1. Ad set mein **1 interest** select karein (e.g., "Home Gym Equipment").
2. **Placement:** "Facebook & Instagram Feeds" (aur koi nahi).
3. **Optimization:** "Conversions" (not traffic).
4. **Creative:** Apna best ad upload karein.
5. **5 days** tak run karne ke baad, **ROAS** check karein. Agar ROAS > 2x hai, toh budget double kar dein.

**Answer Key:**
Hook+CTA, interest-based, $5/day, ROAS>2
