# Day 16 — **Freelancing Mein "Upselling" Kaise Karein: Client Se Zyada Paise Kaise Kamayein**

**Concept:**
Freelancing mein "upselling" ka matlab hai ek client ko extra services ya upgraded packages offer karke unka order value badhana. Yeh ek client ke saath hi zyada kamane ka sabse effective tareeka hai. Upselling tab kaam aata hai jab client pehle se hi aap ke work se impressed ho, isliye yeh trust build karne ke baad hi karna chahiye.

**Example:**
Ek graphic designer ko ek client ne ek logo design karne ke liye hire kiya hai. Client ko logo pasand aata hai, lekin woh abhi aur bhi designs (business card, social media posts) chahte hain. Designer ne pehle hi apne portfolio mein yeh services di hui hain, toh woh client ko propose kar sakta hai: *"Aapka logo toh ready hai! Kya aapko business card aur Instagram post bhi chahiye? Main aapko ek discounted package offer kar sakta hoon."*

**Practice:**
Apne kisi existing client ya potential client ko ek email ya message bhej kar ek upsell proposal likhein. Yeh proposal short, clear aur faydemand honi chahiye.

**Mini Project:**
Ek "Upsell Package" banayein jo aap apne portfolio ya gig description mein add kar sakte hain. Ismein 2-3 extra services hon jinse client ko value mile aur aapki income badhe.

**Answer Key:**
discounted package, extra services, client trust, higher order value
