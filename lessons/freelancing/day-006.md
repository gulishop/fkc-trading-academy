# Day 6 — **Negotiation Ka Art: Client Se "Yes" Kaise Karwayein**

**Concept:**
Negotiation freelancing ka hearth hai—agar aap apne rate par akar nahi rakh sakte, toh pricing strategy ka koi matlab nahi. Yahan seekhna hai ki kaise professional tareeke se "counter offer" karein, client ki objections handle karein, aur win-win deal nikalein. Remember: Client bhi apna budget fixed rakhta hai, lekin aap usko value samjha kar rate badha sakte hain.

**Example:**
Ek client ne aapko $500 ka project offer kiya hai, lekin aapka minimum $700 hai. **Step 1:** Shukriya ke saath "I appreciate the offer!" bol kar shuru karein. **Step 2:** Value batayein: "For $700, I’ll include [X feature] which will save you 20 hours of work." **Step 3:** Flexibility dikhaye: "If budget is tight, we can start with Phase 1 ($500) and add Phase 2 later."

**Practice:**
Apne ek imaginary client se negotiation karne ka email draft karein. Use the 3-step formula above (appreciation + value + flexibility).

**Mini Project:**
Ek real-life negotiation scenario likhein jismein:
- Client ka initial offer ($300)
- Aapka minimum rate ($450)
- 2-3 value points (e.g., "I’ll deliver in 3 days instead of 5")
- Final deal ($380 with 1 extra feature)

**Answer Key:**
gratitude, value-add, phased approach, flexibility
