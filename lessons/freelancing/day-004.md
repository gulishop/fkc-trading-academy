# Day 4 — **Pricing Strategy: Apne Services Ka Rate Kaise Set Karein (Bina Ghate Ke)**

**Concept:**
Freelancing mein pricing ka matlab hai apne time, skill aur effort ka correct value set karna. Agar rate zyada rakha to clients door ho jayenge, kam rakha to ghata ho jayega. Har skill ka market rate hota hai—usko research karke apna rate decide karna hai. Beginners ko initially low rate par bhi accept karna chahiye, lekin time ke saath increase karna hai.

**Example:**
Ek logo design freelancer ka case: Fiverr par beginner logo design gigs ₹500-₹1500 ke beech hoti hain. Agar aap 3 designs offer kar rahe hain, to ₹1000-₹1200 per gig set kar sakte hain. Lekin agar aap 10+ designs offer kar rahe hain, to ₹2000-₹3000 bhi ho sakta hai. Market research ke liye Fiverr/Upwork par similar gigs check karein.

**Practice:**
Apne skill ke liye 3 different pricing levels set karein:
1. Basic package (₹X)
2. Standard package (₹Y)
3. Premium package (₹Z)
Har package mein kya included hai, likhein.

**Mini Project:**
Ek Excel sheet ya Google Sheet banayein jisme:
- Apne skill ke 5-10 competitors ke rates note karein
- Apne 3 pricing levels define karein
- Har level ke features list karein

**Answer Key:**
market research, competitor analysis, value-based pricing, tiered packages
