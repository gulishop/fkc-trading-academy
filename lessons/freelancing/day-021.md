# Day 21 — **Freelancing Mein "AI Tools" Ka Sahi Istemal: Time & Money Save Karne Ka Formula**

**Concept:**
AI tools freelancing ki productivity 10x badha dete hain—chahe content likhna ho, designs banani ho, ya client communication. In tools se repetitive tasks automate karke, aap zyada orders le sakte hain aur quality bhi improve hoti hai. Sabse pehle apni skill ke hisaab se sahi AI tools choose karna hai (e.g., copywriting ke liye Jasper, graphic design ke liye Midjourney).

**Example:**
Ek logo design freelancer hai. Uske liye **Midjourney** ka istemal karke:
1. Client ki requirement ke hisaab se prompt likhna (e.g., "minimalist logo for a coffee shop, black and gold colors").
2. 5-10 variations generate karna.
3. Best 3 options client ko send karna + unpar manual tweaks karna.

**Practice:**
Apni skill ke hisaab se **1 AI tool** choose karke, ek chhota sa task (e.g., blog ka intro paragraph, social media caption, ya logo concept) generate karo. Prompt ko 2-3 baar refine karke best result nikalne ki koshish karo.

**Mini Project:**
Ek **AI-powered portfolio page** banana—jismein:
- Apni 3 best skills mention karo.
- Har skill ke liye AI se generate kiya hua **1 example output** add karo (e.g., agar writer ho to AI se likha hua blog post ka paragraph).
- Page ko Canva ya Carrd par design karo aur shareable link bana lo.

**Answer Key:**
Midjourney, Jasper, prompt-refinement, Canva
