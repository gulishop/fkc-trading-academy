# Day 14 — **Fingerprint Sensor Repair: Broken, Unresponsive ya Glitchy Sensor ka Fix**

**Concept:**
Fingerprint sensor repair mein common issues jaise sensor ka broken hona, unresponsive hona, ya glitchy response (jaise sensor ka bar-bar fail hona) ko diagnose aur fix karna sikhaya jayega. Sensor ke hardware (flex cable damage, sensor ki chip ka loose hona) ya software (driver issue, OS conflict) ki wajah se yeh problems hoti hain. Aaj hum hardware-level troubleshooting par focus karenge.

**Example:**
Agar kisi phone ka fingerprint sensor kaam nahi kar raha, toh pehle check karenge ki sensor ka flex cable properly connected hai ya nahi. Agar cable intact hai, toh sensor ko gently press karke check karenge ki kya sensor ka chip thoda sa move ho raha hai. Agar sensor chip loose hai, toh use reballing ya replacement ke zariye fix kiya ja sakta hai.

**Practice:**
Apne ek old phone ka fingerprint sensor ka flex cable disconnect karke dobara connect karen. Check karen ki sensor ab kaam kar raha hai ya nahi. Agar nahi, toh sensor ke chip ko gently press karke dekhain ki kya sensor ka response improve hota hai.

**Mini Project:**
Ek old phone ka fingerprint sensor remove karke, uske flex cable ko clean karke dobara install karen. Agar sensor kaam karta hai, toh usko repair karke dikhain. Agar nahi, toh sensor ko replace karke test karen.

**Answer Key:**
flex cable check, sensor chip loose, reballing/replacement, test fingerprint
