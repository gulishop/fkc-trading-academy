# Day 24 — **Mobile Charging & Data Port Cleaning: Deep Cleaning Technique**

**Concept:**
Charging aur data port mein dust, lint ya corrosion ki wajah se poor connection hota hai. Is lesson mein advanced cleaning techniques seekhein gaye—jisme ultrasonic cleaner, isopropyl alcohol aur brushes ka istemal shamil hai. Yeh skill zyada time-consuming hai lekin repair success rate 30% tak badha deti hai.

**Example:**
1. Port ko kholne ke liye plastic pry tool use karo.
2. Ultrasonic cleaner (99% isopropyl alcohol + 5-10 min ultrasonic waves) se port ko saaf karo.
3. Soft toothbrush se remaining dust nikal do.
4. Cotton swab (isopropyl alcohol mein bheega hua) se edges clean karo.

**Practice:**
Apne ek old/broken charging port wala phone lein aur upar di gayi steps ko follow karke port ko deep clean karo.

**Mini Project:**
Ek video banao jisme port cleaning process step-by-step dikhaye (30-60 seconds tak). Video ke caption mein likhna: "Agar charging port ka issue hai, toh yeh trick try karen!"

**Answer Key:**
ultrasonic cleaner, isopropyl alcohol, plastic pry tool, cotton swab
