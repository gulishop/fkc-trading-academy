# Day 25 — **Mobile Back Cover & Frame Replacement: Step-by-Step Guide**

**Concept:**
Mobile ke back cover aur frame ko replace karna ek common repair hai jo customers ko bar-bar aata hai (e.g., cracked back ya loose frame). Isme tools (plastic pry tools, screwdriver), spare parts (OEM ya aftermarket), aur careful handling ki zaroorat hoti hai taake internal components (battery, camera, etc.) ko damage na ho.

**Example:**
1. **Back cover remove karo:** Plastic pry tool se back cover ke edges se gently lift karo (force mat lagao).
2. **Screws check karo:** Frame ke screws ko unscrew karo (kuch models mein hidden screws hote hain, e.g., under battery ya SIM tray).
3. **Frame ko alag karo:** Frame ko slowly lift karo, connectors (e.g., fingerprint sensor, rear camera) ko disconnect karne ki zaroorat ho sakti hai.
4. **New frame install karo:** Screws ko tight karo, lekin zyada force mat lagao warna threads damage ho sakte hain.

**Practice:**
Apne ek old mobile ka back cover aur frame remove karo aur phir original frame ko dobara install karo. Har step ko 2-3 baar repeat karo taake confidence aaye.

**Mini Project:**
Ek customer ka mobile lo jiska back cover cracked hai. Uske liye:
- Back cover remove karo.
- New OEM ya aftermarket back cover install karo.
- Mobile ko test karo (charging, buttons, camera).

**Answer Key:**
plastic pry tool, screws, connectors, OEM frame
