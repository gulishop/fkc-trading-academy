# Day 4 — **Android Phone Ko Factory Reset Karna: Hard Reset vs Soft Reset**

**Concept:**
Factory reset se phone ki sari data wipe ho jati hai aur phone jaise new ho jata hai. Soft reset (settings se reset) aur hard reset (recovery mode se reset) ke beech farq samajhna zaroori hai. Yehi tarika hai jab phone hang ho, password bhul gaye ho ya software corruption ho.

**Example:**
Agar phone bar-bar restart ho raha hai aur koi app crash kar raha hai, toh:
1. **Soft Reset:** *Settings > System > Reset > Factory Data Reset* (backup le lena!)
2. **Hard Reset:** Phone off kar ke *Power + Volume Up* dabaye, recovery mode mein *Wipe Data/Factory Reset* select kar ke confirm kar dein.

**Practice:**
Apne ek old phone ya friend ke phone ko soft reset kar ke dekhiye. Backup lena na bhulna!
