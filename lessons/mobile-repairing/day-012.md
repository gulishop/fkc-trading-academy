# Day 12 — **Mobile Charging Circuit Faults: Diagnosis aur Repair**

**Concept:**
Mobile charging circuit mein common faults ko identify karna aur repair karna seekhiye. Charging port se lekar battery tak ka complete path check karna hai—har component (charging IC, fuse, diode, resistor) ki role samajhiye. Faults jaise "not charging", "slow charging", ya "charging but not turning on" ko trace karne ke liye multimeter aur schematics ka use karna hai.

**Example:**
*Problem:* Samsung Galaxy S20 charging nahi kar raha, lekin charging port ko clean karne ke baad bhi same issue hai.
*Diagnosis:*
1. Battery voltage check karo (3.7V se kam?).
2. Charging port ke pins par voltage check karo (5V expected).
3. Charging IC (PMIC) ke input/output pins check karo.
4. Fuse ya resistor (R1201) check karo agar open ho.

**Practice:**
Apne kisi old/broken phone ka charging circuit diagram download karo (Google par "Samsung S20 charging circuit diagram" search karo). Multimeter se charging port ke pins par voltage check karo aur ek fault diagnose karo (e.g., pin 1 par 0V hai, lekin expected 5V hai).

**Mini Project:**
Ek broken charging port wale phone ko lekar:
- Charging port ko replace karo.
- Charging IC ke input/output pins par voltage check karo.
- Agar charging IC faulty hai, to use replace karo ya reball karo.

**Answer Key:**
Battery voltage low, charging port pins 0V, charging IC input 0V, fuse open
