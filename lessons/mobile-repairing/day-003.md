# Day 3 — **Charging Port aur USB-C Port Repair**

**Concept:**
Charging port ya USB-C port ka kharab hona ek common issue hai jo mobile repair business mein frequently aata hai. Yeh port dust, lint, ya accidental damage ki wajah se block ho jata hai, jisse charging aur data transfer mein problem hoti hai. Repair ke liye port ko clean karna, loose connection ko tight karna, ya port ko replace karna shamil hai.

**Example:**
1. **Port Cleaning:** Toothpick ya anti-static brush se port ke andar se dust nikal dein.
2. **Loose Connection Fix:** Port ko gently press karke check karen agar charging reconnect hoti hai.
3. **Port Replacement:** Agar port physically damaged hai, to new port install karne ke liye soldering ya adhesive use karen.

**Practice:**
Apne kisi old phone ke charging port ko khol kar clean karen. Agar port loose hai to tight karen, warna port ko remove karne ka practice karen.

**Mini Project:**
Ek damaged charging port wale phone ko repair karke usko charging aur data transfer ke liye test karen.

**Answer Key:**
port clean, loose tight, replace solder
