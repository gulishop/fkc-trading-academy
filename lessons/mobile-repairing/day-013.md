# Day 13 — **Camera Module Repair: Focus, Zoom aur Lens Issues ka Fix**

**Concept:**
Mobile ke camera module mein focus, zoom ya lens ki problems aam hain—jaise blur images, autofocus ka kaam na karna, ya zoom fail hona. Isse diagnose karne ke liye module ko kholna, connectors check karna, aur lens ya sensor ki cleaning/swap karna seekhna zaroori hai. Agar camera circuit mein short ya broken trace hai, to usko bhi repair karna part hai.

**Example:**
*Step-by-step:*
1. Camera module ko kholne ke baad, lens ko microscope se check karo—agar dust ya scratch hai, to lens clean karo ya replace karo.
2. Autofocus issue ke liye, flex cable ko reball karo ya naya module install karo.
3. Zoom motor ka fault hai? To motor ko test karo (voltage check karo) ya naya motor lagao.

**Practice:**
Apne kisi old phone ka camera module kholo, lens ko clean karo, aur autofocus test karo. Agar blur image aati hai, to lens ya sensor check karo.

**Mini Project:**
Ek broken camera module ko repair karo (lens clean/swap ya flex cable reball karo) aur usko kisi phone mein test karo. Result ko photo/video mein capture karo.

**Answer Key:**
lens clean, flex cable check, autofocus test, replace module
