# Day 7 — **TikTok Par "Live Sessions" Se Engagement Kaise Badhaye**

**Concept:**
TikTok Live ek powerful tool hai jo real-time engagement badhata hai. Iske zariye followers se directly interact karke trust build kar sakte hain, comments ka reply de sakte hain, aur even monetization ke opportunities mil sakte hain. Lekin successful Live ke liye proper planning aur engagement strategies zaroori hain.

**Example:**
Ek gaming creator ne har shanivaar 8 PM par "Gaming Tips Live" shuru kiya. Usne audience se poochha: "Aapka favourite game kya hai?" aur har comment ka reply diya. Result mein uske Live viewers 5x badh gaye aur uske regular viewers bhi increase hue.

**Practice:**
Aaj hi apne mobile par TikTok Live start karne ka plan banao. Topic decide karo (e.g., Q&A, tutorial, behind-the-scenes) aur audience ko notify karne ke liye ek post share karo.

**Mini Project:**
Ek 15-minute TikTok Live session record karo aur dekhlo ki kitne viewers aaye, kitne comments hue, aur engagement rate kya raha. Notes banao ki kya improve kar sakte hain.

**Answer Key:**
engagement boost, real-time interaction, trust building, live notifications
