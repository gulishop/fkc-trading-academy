# Day 5 — **TikTok Par "Hashtag Strategy" — Trending Se Le Kar Niche Target Karne Tak**

**Concept:**
Hashtags TikTok par discoverability ka backbone hain. Sirf trending hashtags use karne se kaam nahi chalta—unhe niche, competition aur apne content type ke hisaab se chunna hota hai. Aaj seekhenge ki kaise hashtags ko research karke, mix karke aur timing ke saath use karke views 2x badhaein.

**Example:**
1. **Research:** TikTok ke search bar mein "fitness" type karo, phir "Hashtags" tab select karo. Dekho ki "fitnesschallenge" (1.2M posts) aur "gymmotivation" (800K posts) ka mix hai.
2. **Mix:** 1-2 broad (#Fitness), 1-2 niche (#HomeWorkout), 1 branded (#YourChannelName) aur 1 trending (#GymTokChallenge).
3. **Placement:** Description ke end mein, pehle 3-4 hashtags sabse relevant likhein (algorithm inhe zyada weightage deta hai).

**Practice:**
Apne niche ke 5 trending hashtags dhundo (TikTok search se ya [TikTok Creative Center](https://www.tiktok.com/business/en/creativecenter) se). Unhe apne next video ke description mein use karo.

**Mini Project:**
Ek "Hashtag Bank" banao: Excel/Notion mein 3 categories ke hashtags save karo:
- **Trending** (high volume, low competition)
- **Niche** (medium volume, high relevance)
- **Branded** (apne channel ke liye unique)
Har video ke saath inmein se 3-5 hashtags randomly select karke use karo.

**Answer Key:**
trending hashtags research, niche relevance, branded hashtag, mix strategy
