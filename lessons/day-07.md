# Day 7 — Elif aur Multiple Conditions

- **Concept:** Ek se zyada conditions check karna
- **Example:**
  ```python
  marks = int(input("Marks: "))
  if marks >= 90:
      print("A Grade")
  elif marks >= 70:
      print("B Grade")
  else:
      print("C Grade")
  ```
- **Practice:** Grading system 4-5 grades ke sath banwayen
- **Mini Project:** "Grade Calculator" — poora grading system (A,B,C,D,F)
