# Day 6 — Facebook Page Se Direct Sales Kaise Karein: Messenger Bot Strategy

**Concept:**
Facebook Messenger se sales karne ka matlab hai automated messages aur chatbots ka istemal karke customers ko engage karna aur unse directly purchase karwana. Iske liye aapko Messenger bot setup karna hoga jo 24/7 customers ke questions ka jawab de aur unhe buying process tak le jae. Isse response time kam hota hai aur conversion rates bhi badhte hain.

**Example:**
1. **Bot Setup:** ManyChat ya Chatfuel jaise tools se ek simple bot banayein jo "Hi! Aapko kya chahiye?" pooche.
2. **Quick Replies:** Options add karein jaise "Products," "Pricing," "Contact Support."
3. **Automated Flow:** Agar koi "Products" select karta hai to bot usko product catalog ya link bhej de.
4. **Follow-up:** Agar customer 24 ghante tak respond nahi karta to bot "Aapka order pending hai, kya aapko help chahiye?" message bhej de.

**Practice:**
Apne Facebook Page par ManyChat bot install karein aur ek simple flow banayein jo customers ko "Buy Now" button tak le jae.

**Mini Project:**
Ek Messenger bot banayein jo:
- Welcome message send kare
- 3 product options offer kare
- Agar koi product select kare to usko uska link ya pricing bhej de
- Agar koi "Help" select kare to aapke inbox ka link bhej de

**Answer Key:**
Welcome message, product options, pricing link, help option
