# Day 5 — Facebook Ads Se Paise Kamana Shuru Karein

**Concept:**
Facebook Ads ek powerful tool hai jo aapke page par targeted traffic aur sales lane mein madad karta hai. Isse aap apne audience ko unke interests, location aur behavior ke hisaab se reach kar sakte hain. Basics seekhkar aap ads create karna shuru kar sakte hain bina zyada kharch kiye.

**Example:**
1. Apne Facebook Page par "Boost Post" button par click karein.
2. Target audience select karein (e.g., 25-35 age group, Lahore mein rehne wale, fitness mein interested).
3. Budget set karein (e.g., Rs. 500/day).
4. Ad create karein aur "Boost" par click karein.

**Practice:**
Apne page par kisi ek post ko select karein aur usko Rs. 300-500 ke budget ke saath boost karein. Target audience ko apne niche ke hisaab se set karein.

**Mini Project:**
Ek 3-day Facebook Ad campaign plan banaein:
- Day 1: Awareness ke liye video ad
- Day 2: Engagement ke liye carousel ad
- Day 3: Conversion ke liye lead ad

**Answer Key:**
Post select, audience target, budget set, ad launch
