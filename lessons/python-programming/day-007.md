# Day 7 — Error Handling: Try-Except Blocks

**Concept:**
Programs mein errors aana normal hai—jaise file na milna, division by zero, ya invalid input. `try-except` blocks in Python errors ko "pakad" kar unko handle karne mein madad karte hain. Isse program crash hone se bachta hai aur user-friendly messages show karte hain.

**Example:**
```python
try:
    num = int(input("Apna number likhein: "))
    result = 10 / num
    print("Result:", result)
except ValueError:
    print("Error: Number hi likhna tha!")
except ZeroDivisionError:
    print("Error: Zero se divide nahi ho sakta!")
```

**Practice:**
Ek program banayein jo user se ek file ka naam le aur usko read kare. Agar file na mile to "File not found!" print kare, warna uski content dikhaye.
