# Day 9 — Python Modules: Reusing Code Like a Pro

**Concept:**
Modules Python files hain jinse hum reusable code (functions, classes, variables) ko organize karte hain. Libraries (jaise `math`, `random`) pre-built modules hain jo extra functionality provide karte hain. `import` statement se hum in modules ko apne program mein include karte hain.

**Example:**
1. Ek `calculator.py` module banayein:
```python
# calculator.py
def add(a, b):
    return a + b
```
2. Main program mein use karen:
```python
import calculator
result = calculator.add(5, 3)
print(result)  # Output: 8
```
3. Direct functions import karen:
```python
from calculator import add
print(add(5, 3))  # Output: 8
```

**Practice:**
