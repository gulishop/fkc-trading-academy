# Day 12 — Lambda Functions aur Higher-Order Functions

**Concept:**
Lambda functions Python mein chhoti, anonymous functions hain jo `def` ke bina ek line mein define hoti hain. Higher-order functions wo hain jo doosri functions ko arguments ke taur par le sakti hain ya return kar sakti hain (jaise `map()`, `filter()`, `sorted()`).

**Example:**
```python
# Lambda function
square = lambda x: x * x
print(square(5))  # Output: 25

# Higher-order function example
numbers = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, numbers))
print(squared)  # Output: [1, 4, 9, 16]
```

**Practice:**
Ek lambda function banayein jo do numbers ka sum return kare, phir use `map()` ke saath ek list ke har element par apply kare.
