# Day 15 — Object-Oriented Programming: Encapsulation aur Abstraction

**Concept:**
Encapsulation aur abstraction OOP ke do powerful concepts hain jo code ko secure aur maintainable banate hain. Encapsulation ka matlab hai data aur uske functions ko ek single unit (class) mein bundle karna, jabki abstraction ka matlab hai complex details ko chhupa kar sirf zaroori functionality provide karna.

**Example:**
```python
class BankAccount:
    def __init__(self, balance=0):
        self.__balance = balance  # Encapsulation: private variable

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            print(f"Deposited: {amount}")

    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            print(f"Withdrawn: {amount}")
        else:
            print("Insufficient balance!")

    def get_balance(self):  # Abstraction: sirf balance show karna
        return self.__balance
```
