# Day 11 — Python Data Structures: Stacks aur Queues

**Concept:**
Stacks (LIFO - Last In First Out) aur Queues (FIFO - First In First Out) Python mein common data structures hain jo data ko organize karte hain. Stacks mein last add kiye gaye item pehle remove hota hai (jaise plates ka stack), jabki queues mein pehle add kiye gaye item pehle remove hote hain (jaise ticket line). Inhe `list` ya `collections.deque` se implement kar sakte hain.

**Example:**
```python
# Stack (LIFO)
stack = []
stack.append(1)  # Push
stack.append(2)
stack.append(3)
print(stack.pop())  # 3 (last in, first out)

# Queue (FIFO)
from collections import deque
queue = deque()
queue.append(1)  # Enqueue
queue.append(2)
queue.append(3)
print(queue.popleft())  # 1 (first in, first out)
```
