# Day 20 — Web Scraping: Advanced Techniques aur Data Extraction

**Concept:**
Aaj hum web scraping ke advanced techniques seekhenge. Hum `BeautifulSoup` aur `requests` libraries ka istemal karke dynamic websites se data extract karenge, aur `selenium` ka use karke JavaScript-rendered content ko scrape karenge. Isse hum un websites se bhi data le sakte hain jo pehle accessible nahi the.

**Example:**
1. **Dynamic Content Scraping:**
```python
from selenium import webdriver
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager

driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()))
driver.get("https://example.com/dynamic-page")
elements = driver.find_elements("tag name", "h2")
for elem in elements:
    print(elem.text)
driver.quit()
```

2. **Handling Pagination:**
```python
import requests
from bs4 import BeautifulSoup

base_url = "https://example.com/page="
for page in range(1, 6):
    url = base_url + str(page)
    response = requests.get(url)
    soup = BeautifulSoup(response.text, 'html.parser')
    items = soup.find_all("div", class_="item")
    for item in items:
        print(item.text.strip())
```
