# Day 21 — Python Packages aur pip: Libraries Install aur Manage Karna

**Concept:**
Python mein libraries (packages) install karne ke liye `pip` (Package Installer for Python) use hota hai. Ye ek command-line tool hai jo external libraries ko download aur install karta hai. Har Python project mein dependencies manage karne ke liye `pip` essential hai. Aaj hum seekhenge ki kaise `pip` use karke libraries install karni hain aur unhe apne code mein import karna hai.

**Example:**
1. **Check pip version:**
   Terminal/Command Prompt mein yeh command run karo:
   ```bash
   pip --version
   ```
   Agar installed hai to version show hoga, nahi to error aayega.

2. **Library install karna:**
   Ek popular library `requests` install karne ke liye:
   ```bash
   pip install requests
   ```

3. **Library use karna:**
   Python file mein:
   ```python
   import requests
   response = requests.get("https://api.github.com")
   print(response.status_code)
   ```

**Practice:**
Apne system par `pip` install karne ke baad, ek aur library `python-dotenv` install karo aur verify karo ki wo successfully install hui hai.

**Mini Project:**
Ek chhota project banayein jo:
1. `pip` se `requests` library install kare.
