# Day 17 — Working with JSON Data: Read, Write, and Parse

**Concept:**
JSON (JavaScript Object Notation) is a lightweight data format used everywhere—APIs, config files, and data storage. Python’s built-in `json` module lets you convert Python dictionaries to JSON strings (`json.dump()`/`json.dumps()`) and back (`json.load()`/`json.loads()`). It’s essential for web apps, APIs, and config management.

**Example:**
```python
import json

# Writing to a JSON file
data = {"name": "Ali", "age": 25, "city": "Lahore"}
with open("user.json", "w") as file:
    json.dump(data, file, indent=4)  # indent for pretty formatting

# Reading from a JSON file
with open("user.json", "r") as file:
    loaded_data = json.load(file)
print(loaded_data["name"])  # Output: Ali
```
