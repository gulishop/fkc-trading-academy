# Day 8 — Object-Oriented Programming: Classes aur Objects

**Concept:**
OOP mein hum code ko real-world entities (classes) aur unke instances (objects) mein organize karte hain. Ek class blueprint hoti hai (jaise 'Car'), jabki object us blueprint ka actual implementation hota hai (jaise 'my_car = Car()'). Isse code reusable, maintainable aur scalable ban jata hai.

**Example:**
```python
class Car:
    def __init__(self, brand, model):
        self.brand = brand
        self.model = model

    def display(self):
        print(f"Car: {self.brand} {self.model}")

# Object creation
my_car = Car("Toyota", "Corolla")
my_car.display()  # Output: Car: Toyota Corolla
```

**Practice:**
Ek `Student` class banaye jisme `name`, `age`, aur `grade` attributes hon. Ek method `display_info()` add kare jo yeh details print kare. Phir `student1 = Student("Ali", 15, "10th")` object create karke uski info display kare.
