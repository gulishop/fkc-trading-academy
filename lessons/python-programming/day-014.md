# Day 14 — Object-Oriented Programming: Inheritance aur Polymorphism

**Concept:**
Inheritance ek OOP concept hai jisme ek class (child class) doosri class (parent class) ke properties aur methods inherit karti hai. Polymorphism ka matlab hai "many forms" — yani ek hi method ka different classes mein alag-alag implementations hona. Ye code reusability aur flexibility badhata hai.

**Example:**
```python
class Animal:  # Parent class
    def speak(self):
        print("Animal sound")

class Dog(Animal):  # Child class (inherits from Animal)
    def speak(self):  # Polymorphism (override)
        print("Bark!")

class Cat(Animal):
    def speak(self):
        print("Meow!")

animals = [Dog(), Cat()]
for animal in animals:
    animal.speak()  # Same method call, different outputs
```

**Practice:**
Ek `Vehicle` class banao jisme `start()` method ho. Phir `Car` aur `Bike` classes banayein jo `Vehicle` se inherit karein aur `start()` method ko override karke alag-alag output dikhaye.
