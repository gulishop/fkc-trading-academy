# Day 2 — Variables, Data Types aur Input/Output

**Concept:**
Variables Python mein boxes ki tarah hain jinme hum data store karte hain. Har variable ka ek data type hota hai (jaise number, text, ya boolean). Input/output ka matlab hai program aur user ke beech communication—user se data lena (input) aur results show karna (output).

**Example:**
```python
# Variable declare karna
name = "Ali"  # String (text)
age = 25      # Integer (number)
height = 5.9  # Float (decimal number)
is_student = True  # Boolean (True/False)

# Input lena
user_name = input("Apna naam likhein: ")
print("Hello,", user_name)

# Data type check karna
print(type(age))  # Output: <class 'int'>
```
