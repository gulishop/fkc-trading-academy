# Day 13 — Advanced String Manipulation: Formatting aur Advanced Operations

**Concept:**
Aaj hum strings ke advanced operations seekhenge - formatting (f-strings, .format()), string methods (split, join, replace), aur regular expressions (regex) ke basics. Strings Python mein sabse zyada use hone wale data types hain, inke advanced features se code readable aur powerful ban jaata hai.

**Example:**
```python
name = "Ali"
age = 25
# f-string se formatting
print(f"Mera naam {name} hai aur main {age} saal ka hoon")

# String methods
text = "python programming"
print(text.upper())        # PYTHON PROGRAMMING
print(text.split())        # ['python', 'programming']
print("-".join(text.split()))  # python-programming

# Regex se email validation
import re
email = "test@example.com"
if re.match(r"[^@]+@[^@]+\.[^@]+", email):
    print("Valid email")
```
