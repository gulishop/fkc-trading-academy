# Day 3 — If-Else aur Loops: Program Flow Control

**Concept:**
Aaj hum seekhenge ke kaise Python programs ko "decision-making" aur "repetition" ke zariye control karte hain. `if-else` statements se programs apne hisaab se decisions le sakte hain (jaise agar temperature zyada ho to AC chalana). `for` aur `while` loops se repetitive tasks automate kar sakte hain (jaise 100 numbers print karna ya user se input lena jab tak sahi na ho).

**Example:**
1. **If-Else:**
```python
temperature = 35
if temperature > 30:
    print("AC chala do!")
else:
    print("Pani piyo.")
```
2. **For Loop:**
```python
for i in range(5):  # 0 se 4 tak print karega
    print(f"Number: {i}")
```
3. **While Loop:**
```python
count = 0
while count < 3:
    print("Hello!")
    count += 1
```

**Practice:**
Ek program banayein jo user se ek number input le aur check kare:
- Agar number even hai to print kare "Even number"
- Agar odd hai to print kare "Odd number"
