# Day 10 — Web Scraping Basics: Data Extract Karna

**Concept:**
Web scraping Python mein ek powerful technique hai jisse hum websites se data extract kar sakte hain. `requests` aur `BeautifulSoup` libraries ka istemal karke hum HTML pages parse kar sakte hain aur required data nikal sakte hain. Ye beginner-friendly hai aur real-world applications jaise price comparison, news aggregation, ya research mein kaam aata hai.

**Example:**
1. Install libraries: `pip install requests beautifulsoup4`
2. Ek website ka HTML fetch karo:
```python
import requests
from bs4 import BeautifulSoup

url = "https://example.com"
response = requests.get(url)
soup = BeautifulSoup(response.text, 'html.parser')
```
3. Specific data extract karo (e.g., sabhi `<h2>` tags):
```python
headings = soup.find_all('h2')
for heading in headings:
    print(heading.text)
```

**Practice:**
Apni manpasand website (jaise news portal ya e-commerce site) ka URL lein aur uske sabhi `<a>` tags ke text aur links print karein.
