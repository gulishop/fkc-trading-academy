# Day 6 — Object-Oriented Programming (OOP) Basics

**Concept:**
OOP programming ka ek powerful tareeqa hai jo real-world entities (objects) ko code mein represent karta hai. Classes aur objects ka istemal karke code ko organized, reusable aur maintainable banaya ja sakta hai. Aaj hum `__init__`, methods, aur attributes jaise basic OOP concepts seekhenge.

**Example:**
Ek `Car` class banate hain jo `brand`, `model`, aur `year` store karegi:
```python
class Car:
    def __init__(self, brand, model, year):
        self.brand = brand
        self.model = model
        self.year = year

    def display_info(self):
        print(f"Car: {self.brand} {self.model}, Year: {self.year}")

# Object create karna
my_car = Car("Toyota", "Corolla", 2022)
my_car.display_info()  # Output: Car: Toyota Corolla, Year: 2022
```
