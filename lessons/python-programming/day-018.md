# Day 18 — Web Scraping Basics with Python

**Concept:**
Aaj hum seekhenge ke kaise Python ki madad se websites se data extract kar sakte hain. Web scraping se hum automatic tareeke se information collect kar sakte hain jaise product prices, news articles, ya contact details. Iske liye hum `requests` aur `BeautifulSoup` libraries use karenge.

**Example:**
1. Pehle `pip install requests beautifulsoup4` kar ke libraries install kar lein.
2. Ek simple webpage ka HTML fetch karne ke liye:
```python
import requests
from bs4 import BeautifulSoup

url = "https://example.com"
response = requests.get(url)
soup = BeautifulSoup(response.text, 'html.parser')
print(soup.prettify())  # Page ka pura HTML structure
```
3. Ab kisi specific element (jaise sabse pehla `<h1>`) ko extract karne ke liye:
```python
heading = soup.find('h1').text
print(heading)
```
