# Day 5 — Functions: Reusable Code Blocks

**Concept:**
Functions ek reusable code block hote hain jo specific task perform karte hain. Inse code ko organize karne, repeat hone se bachne aur program ko modular banane mein help milti hai. Python mein `def` keyword se functions banaye jate hain.

**Example:**
```python
def greet(name):
    print(f"Hello, {name}!")

greet("Ali")  # Output: Hello, Ali!
```
