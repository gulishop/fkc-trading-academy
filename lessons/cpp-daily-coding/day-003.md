# Day 3 — Operators aur Type Conversion: Apne Programs Ko Aur Powerful Banana

**Concept:**
Operators C++ mein calculations aur decisions karne ke liye hote hain (jaise +, -, *, /, %, ==, !=, &&, ||). Type conversion matlab ek data type ko doosre mein convert karna (jaise `int` ko `float` mein). Ye sab programming ko flexible aur efficient banata hai.

**Example:**
```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 5, b = 2;
    float result = a / b; // Implicit conversion (int/float → float)
    cout << "Division: " << result << endl; // Output: 2.5

    // Explicit conversion (C-style)
    int x = 10;
    float y = (float)x / 3; // Output: 3.333...
    cout << "Explicit: " << y << endl;
    return 0;
}
```
