# Day 12 — Constructors aur Destructors: Objects Ko Initialize aur Clean Karna

**Concept:**
Jab hum koi object banate hain, uske liye memory allocate hoti hai. **Constructor** ek special function hai jo object ke banne ke waqt automatically call hota hai—yahan hum object ko initial values de sakte hain. **Destructor** bhi ek special function hai jo object ke destroy hone par call hota hai—yahan hum resources (jaise memory) clean kar sakte hain. In dono se hum objects ko better control kar sakte hain.

**Example:**
```cpp
class Car {
private:
    string model;
    int year;
public:
    // Constructor (same name as class)
    Car(string m, int y) {
        model = m;
        year = y;
        cout << "Car created: " << model << endl;
    }
    // Destructor
    ~Car() {
        cout << "Car destroyed: " << model << endl;
    }
};

int main() {
    Car myCar("Tesla Model 3", 2023); // Constructor call
    return 0; // Destructor call hoga jab program end hoga
}
```
Output:
```
Car created: Tesla Model 3
Car destroyed: Tesla Model 3
```

**Practice:**
Ek `Book` class banaiye jisme `title` aur `author` ho. Constructor mein `cout` se "Book created: [title]" print karein. Destructor mein "Book destroyed: [title]" print karein. `main()` mein do objects banaiye aur unko destroy hone do.

Ek `Student` class banaiye jisme `name`, `rollNo`, aur `marks` ho. Constructor mein `marks` ko initialize karein, aur ek function `display()` banaiye jo student ki details print kare. `main()` mein 3 students ke objects banaiye aur unki details display karein.
