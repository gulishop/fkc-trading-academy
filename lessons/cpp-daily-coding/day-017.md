# Day 17 — **STL Containers: Vectors, Maps, aur Sets**

**Concept:**
C++ ka STL (Standard Template Library) powerful containers provide karta hai jo data ko efficiently store aur manage karne mein help karte hain. `vector` dynamic arrays jaisa hai, `map` key-value pairs store karta hai (jaise dictionary), aur `set` unique elements ko sorted order mein rakhta hai. Ye sab hi generic programming ko easy banate hain.

**Example:**
```cpp
#include <iostream>
#include <vector>
#include <map>
#include <set>
using namespace std;

int main() {
    // Vector example
    vector<int> numbers = {1, 2, 3};
    numbers.push_back(4); // Add 4 at end

    // Map example (key-value pairs)
    map<string, int> ages;
    ages["Ali"] = 25;
    ages["Sana"] = 30;

    // Set example (unique elements)
    set<int> uniqueNums = {5, 2, 8, 2}; // Only {2,5,8} store hoga

    return 0;
}
```

**Practice:**
Ek program banaye jo:
1. User se 5 numbers input le aur unko ek `vector` mein store kare.
2. Vector ko print kare.
3. Vector ke elements ko descending order mein sort kare (hint: `sort` function aur `greater<int>()`).
