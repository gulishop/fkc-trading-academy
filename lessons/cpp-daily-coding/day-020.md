# Day 20 — **Recursion in C++: Functions Ko Khud Ko Call Karna**

**Concept:**
Recursion ek aisa tareeqa hai jisme function khud ko bhi call kar sakta hai. Isse complex problems (jaise factorial, Fibonacci series) ko chote chunks mein solve kar sakte hain. Base case (roknay ka point) hona zaroori hai warna infinite loop ban jayega.

**Example:**
```cpp
int factorial(int n) {
    if (n == 0) return 1; // Base case
    return n * factorial(n-1); // Recursive call
}
```
Yahan `factorial(3)` pehle `3 * factorial(2)` karega, jo `2 * factorial(1)` hoga, aur `factorial(1)` `1 * factorial(0)` return karega. `factorial(0)` base case hai jo `1` return karta hai.

**Practice:**
Ek function `fibonacci(n)` likho jo `n`th Fibonacci number return kare (0, 1, 1, 2, 3, 5...). Hint: `fibonacci(n) = fibonacci(n-1) + fibonacci(n-2)`.
