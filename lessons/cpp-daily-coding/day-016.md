# Day 16 — **File Handling in C++: Data Ko Save aur Read Karna**

**Concept:**
C++ mein files ke zariye data ko disk par save aur read kar sakte hain. `fstream` library se hum `ofstream` (write), `ifstream` (read), aur `fstream` (both) use karte hain. Files ka istemal logs, configurations, ya user data store karne ke liye hota hai.

**Example:**
```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    // File create karke write karna
    ofstream outFile("data.txt");
    outFile << "Hello, C++ File Handling!";
    outFile.close();

    // File read karna
    ifstream inFile("data.txt");
    string line;
    getline(inFile, line);
    cout << "File content: " << line << endl;
    inFile.close();
    return 0;
}
```

**Practice:**
Ek program likho jo user se 3 numbers input le aur unko `numbers.txt` file mein save kar de. Phir us file ko read karke numbers ko sum karke print karo.
