# Day 6 — Functions: Code Ko Reusable aur Zyada Efficient Banana

**Concept:**
Functions ek block of code hote hain jo ek specific task perform karte hain. Inhe reuse karke apna code clean, organized aur easy-to-maintain rakh sakte hain. Functions parameters accept karte hain aur values return kar sakte hain.

**Example:**
```cpp
#include <iostream>
using namespace std;

// Function declaration
int addNumbers(int a, int b) {
    return a + b;
}

int main() {
    int num1 = 5, num2 = 7;
    int result = addNumbers(num1, num2); // Function call
    cout << "Sum: " << result << endl;
    return 0;
}
```

**Practice:**
Ek function `isEven()` banaye jo ek integer parameter le aur return kare `true` agar number even ho, warna `false`.

**Mini Project:**
Ek simple calculator program banaye jo user se do numbers aur ek operator (+, -, *, /) input le aur function ka use karke result calculate kare.
