# Day 1 — C++ Setup aur "Hello World" Program

**Concept:**
Aaj hum C++ programming shuru karne se pehle apne system par C++ compiler aur IDE (Integrated Development Environment) setup karenge. Compiler code ko machine language mein translate karta hai, jabki IDE coding, debugging aur running ko asaan banata hai. Pehle program ko "Hello World" kehte hain—yeh programming ki starting point hoti hai.

**Example:**
1. **Compiler Install karein:**
   - Windows: [MinGW-w64](https://www.mingw-w64.org/) download karein (ya [MSYS2](https://www.msys2.org/)).
   - Mac: Terminal mein `xcode-select --install` run karein.
   - Linux: `sudo apt install g++` (Ubuntu/Debian) ya `sudo dnf install gcc-c++` (Fedora).

2. **IDE Install karein:**
   - [VS Code](https://code.visualstudio.com/) (lightweight, extensions: "C/C++" aur "Code Runner").
   - Ya [Code::Blocks](https://www.codeblocks.org/) (simple IDE).

3. **Pehl program likhein:**
   ```cpp
   #include <iostream>
   using namespace std;

   int main() {
       cout << "Hello World!" << endl;
       return 0;
   }
   ```
   - `g++ hello.cpp -o hello` se compile karein.
   - `./hello` (Linux/Mac) ya `hello.exe` (Windows) se run karein.

**Practice:**
Apne system par C++ compiler aur VS Code setup karein, aur upar wala "Hello World" program run karein. Screenshot ya terminal output share karein.
