# Day 11 — **Object-Oriented Programming: Classes aur Objects**

**Concept:**
C++ mein OOP (Object-Oriented Programming) ka concept classes aur objects par based hai. Class ek blueprint hoti hai jisme data (variables) aur functions (methods) define kiye hote hain. Object us class ka ek instance hota hai. Isse real-world entities (jaise car, student) ko programming mein represent karna easy ho jata hai.

**Example:**
```cpp
#include <iostream>
#include <string>
using namespace std;

class Car {  // Class definition
public:
    string brand;
    int year;

    void display() {  // Method
        cout << "Brand: " << brand << ", Year: " << year << endl;
    }
};

int main() {
    Car myCar;  // Object creation
    myCar.brand = "Toyota";
    myCar.year = 2020;
    myCar.display();  // Method call
    return 0;
}
```
Output:
`Brand: Toyota, Year: 2020`
