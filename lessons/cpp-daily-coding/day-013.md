# Day 13 — Encapsulation: Data Ko Chhupa Kar Secure Rakhein

**Concept:**
Encapsulation ka matlab hai apne data (variables) aur uske functions ko ek "capsule" mein band karna taake bahr wale code ko pata na chale ki andar kya ho raha hai. Isse data hiding hota hai aur code zyada secure aur maintainable ban jata hai. Har class ka internal state private rakha jata hai aur usko access karne ke liye public methods (getters/setters) provide kiye jate hain.

**Example:**
```cpp
class BankAccount {
private:
    double balance;  // Encapsulated data (hidden from outside)
public:
    void deposit(double amount) {
        if (amount > 0) balance += amount;
    }
    double getBalance() {  // Getter method
        return balance;
    }
};

int main() {
    BankAccount account;
    account.deposit(1000);
    cout << "Balance: " << account.getBalance();  // Only via getter
    // cout << account.balance;  // Error: balance private hai
}
```

**Practice:**
Ek `Student` class banayein jisme `name` aur `marks` private hon. Public methods `setName()`, `getName()`, `setMarks()`, aur `getMarks()` banayein. `main()` mein ek student ka naam aur marks set karke print karwayein.

**Mini Project:**
Ek `TemperatureConverter` class banayein jo Celsius aur Fahrenheit ke beech convert kar sake. Private variables `celsius` rakhein aur public methods `setCelsius()`, `getCelsius()`, `toFahrenheit()`, aur `toCelsius()` provide karein.
