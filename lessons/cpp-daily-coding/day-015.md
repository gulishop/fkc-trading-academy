# Day 15 — **Exception Handling: Errors Ko Gracefully Handle Karna**

**Concept:**
C++ mein exceptions (errors) ko handle karne ke liye `try`, `catch`, aur `throw` keywords use hote hain. Runtime errors (jaise file na milna, invalid input) ko program crash hone se pehle handle karna seekhiye. `try` block mein risky code likha jata hai, `catch` block error ko catch karta hai, aur `throw` se manually error bheja jata hai.

**Example:**
```cpp
#include <iostream>
using namespace std;

int divide(int a, int b) {
    if (b == 0) throw "Division by zero error!";
    return a / b;
}

int main() {
    try {
        int result = divide(10, 0);
        cout << "Result: " << result;
    }
    catch (const char* error) {
        cout << "Error caught: " << error;
    }
    return 0;
}
```
*Output:* `Error caught: Division by zero error!`

**Practice:**
Ek `squareRoot()` function banaye jo negative number ka square root calculate kare. Agar negative number input ho, to `throw "Negative number ka square root nahi hota!"` karke error handle kare.
