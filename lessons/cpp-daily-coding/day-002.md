# Day 2 — Variables aur Data Types: Apne Programs Ko Smarter Banana

**Concept:**
Variables memory mein storage ke liye containers hote hain. Har variable ka ek data type hota hai (jaise int, float, char) jo batata hai ke usme kya type ka data store hoga. Input/output (cin/cout) se user se data le sakte hain aur results show kar sakte hain.

**Example:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 25;          // Integer variable
    float price = 19.99;   // Floating-point variable
    char grade = 'A';      // Character variable

    cout << "Age: " << age << endl;
    cout << "Price: $" << price << endl;
    cout << "Grade: " << grade << endl;

    return 0;
}
```

**Practice:**
Ek program banayein jo user se **name** (string), **age** (int), aur **height** (float) input le aur phir sabko ek line mein print kare.

**Mini Project:**
Ek **Simple Calculator** banayein jo do numbers input le aur un par +, -, *, / operations perform karke results show kare.
