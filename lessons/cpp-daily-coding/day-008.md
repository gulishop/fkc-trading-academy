# Day 8 — Structures (struct): Custom Data Types Banana

**Concept:**
Aaj hum `struct` ke zariye apne khud ke custom data types banayenge. `struct` se hum multiple variables ko ek single unit mein group kar sakte hain. Yeh arrays ki tarah hota hai lekin alag-alag data types ke variables store karne ke liye zyada flexible hai. `struct` se code readable aur organized hota hai.

**Example:**
```cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int age;
    float gpa;
};

int main() {
    Student s1; // struct ka object banaya
    s1.name = "Ali";
    s1.age = 20;
    s1.gpa = 3.8;

    cout << "Name: " << s1.name << endl;
    cout << "Age: " << s1.age << endl;
    cout << "GPA: " << s1.gpa << endl;
    return 0;
}
```

**Practice:**
Ek `Book` struct banayein jisme `title`, `author`, aur `price` store ho sakte hain. Phir `main()` mein ek book ka object banayein aur uske details print karein.

**Mini Project:**
Ek `Car` struct banayein jisme `model`, `year`, aur `isElectric` (boolean) ho. 3 cars ke objects banayein aur unki details ek table ki shakal mein print karein.
