# Day 19 — **Memory Management in C++: Smart Pointers aur Manual Control**

**Concept:**
C++ mein memory management manual bhi ho sakti hai (new/delete) aur automatic bhi (smart pointers). Smart pointers (`unique_ptr`, `shared_ptr`, `weak_ptr`) automatically memory ko cleanup karte hain, jab unka scope khatam hota hai. Ye memory leaks aur dangling pointers se bachate hain. Manual control (`new`/`delete`) zyada control deta hai lekin risk bhi zyada hai.

**Example:**
```cpp
#include <memory>
#include <iostream>
using namespace std;

// Manual (Risky)
int* manualPtr = new int(42);
cout << *manualPtr;
delete manualPtr; // Bhul jane par memory leak!

// Smart (Safe)
unique_ptr<int> smartPtr = make_unique<int>(42);
cout << *smartPtr; // No need to delete!
```

**Practice:**
Ek program likho jo:
1. Ek `int` allocate kare `new` se.
2. Uske value ko double karke print kare.
3. Memory manually free kare.
4. Same program ko `unique_ptr` se bhi likho aur compare karo.

**Mini Project:**
Ek simple `Book` class banayein jo:
- `title` aur `author` store kare.
- Constructor mein memory allocate kare (`new` se).
- Destructor mein memory free kare (`delete` se).
- `display()` function se details print kare.
- `unique_ptr<Book>` se object banayein aur test kare.
