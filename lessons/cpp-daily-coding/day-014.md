# Day 14 — **Templates in C++: Generic Programming**

**Concept:**
Templates C++ mein ek powerful feature hain jo aapko generic functions aur classes banane deta hai. Yani ek hi code multiple data types ke liye kaam karega—jaise `int`, `float`, ya `string`. Isse code reusability badhti hai aur type safety bhi maintain hoti hai.

**Example:**
```cpp
#include <iostream>
using namespace std;

// Generic function jo kisi bhi type ke do numbers ko add karega
template <typename T>
T add(T a, T b) {
    return a + b;
}

int main() {
    cout << add(5, 3) << endl;       // int
    cout << add(3.14, 2.71) << endl; // float
    cout << add<string>("Hello, ", "World!") << endl; // string
    return 0;
}
```

**Practice:**
Ek `template` function `max()` banayein jo do values mein se badi value return kare. `int`, `float`, aur `char` types ke liye test karein.

**Mini Project:**
Ek `Calculator` class template banayein jo `add`, `subtract`, `multiply`, aur `divide` operations perform kar sake. `int` aur `double` types ke liye test karein.

**Answer Key:**
