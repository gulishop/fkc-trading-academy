# Day 9 — **Pointers: Memory Addresses Ko Samajhna Aur Use Karna**

**Concept:**
Pointers C++ ki sabse powerful features mein se ek hain. Ye variables ki memory address store karte hain. Pointers se aap direct memory ko access kar sakte hain, dynamic memory allocation kar sakte hain, aur functions se values return kar sakte hain (by reference). Basics mein hum seekhenge ki pointer kaise declare karte hain, address-of operator (`&`) aur dereference operator (`*`) ka istemal kaise hota hai.

**Example:**
```cpp
int num = 10;       // Ek integer variable
int *ptr = &num;    // Pointer jo num ka address store karta hai

cout << "num ka address: " << ptr << endl;  // Memory address print hoga
cout << "num ki value: " << *ptr << endl;   // Dereference se value milti hai (10)
```

**Practice:**
Ek program likho jo:
1. Ek integer variable `age` declare kare (value: 25).
2. Uske address ko ek pointer `agePtr` mein store kare.
3. Pointer ka use karke `age` ki value ko 30 mein update kare.
4. Dono values (original aur updated) print karo.
