# Day 10 — References: Variables Ka Dusra Naam

**Concept:**
References ek variable ka *alias* hota hai – ek naya naam jo kisi existing variable ko point karta hai. Pointers ki tarah memory address store karne ke bajaye, reference *directly* original variable se connect hota hai. References ko declare karne ke baad change nahi kiya ja sakta (unchangeable address), jabki pointers ko reassign kiya ja sakta hai.

**Example:**
```cpp
int main() {
    int x = 10;
    int &ref = x;  // 'ref' ab 'x' ka reference hai

    ref = 20;      // 'x' bhi change ho jayega
    cout << x;     // Output: 20
    cout << &x;    // Memory address
    cout << &ref;  // Same address as x
}
```

**Practice:**
Ek program likho jo:
1. Ek integer variable `num` declare kare (value = 5).
2. Uske liye ek reference `numRef` banaye.
3. `numRef` ki value 15 kar de.
4. Print kare `num` aur `numRef` ki values.

**Mini Project:**
Ek simple "Bank Account" system banaye:
- Ek `balance` variable ho (initial value = 1000).
- Uske liye ek reference `account` banaye.
- Ek function `deposit()` jo `account` ko parameter le aur balance badhaye.
- Ek function `withdraw()` jo `account` se paise katre aur negative balance na ho.
- Main function mein 200 deposit karo aur 500 nikal kar print karo.

**Answer Key:**
num=15,numRef=15,balance=1500,account=500
