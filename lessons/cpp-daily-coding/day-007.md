# Day 7 — Strings aur String Functions: Text Ko Control Karna Seekho

**Concept:**
Strings C++ mein text store karne ka tareeqa hain. `string` data type use karke hum words, sentences ya paragraphs ko handle kar sakte hain. Built-in string functions jaise `length()`, `substr()`, `find()`, aur `replace()` se hum text ko manipulate kar sakte hain.

**Example:**
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string greeting = "Hello, Students!";
    cout << "Original: " << greeting << endl;

    // Length check
    cout << "Length: " << greeting.length() << endl;

    // Substring (index 7 se 15 tak ka hissa)
    cout << "Substring: " << greeting.substr(7, 8) << endl;

    // Replace (index 0 se 5 tak ko "Hi" se badal do)
    greeting.replace(0, 5, "Hi");
    cout << "After replace: " << greeting << endl;

    return 0;
}
```
