# Day 18 — **Lambda Functions: Inline Functions Ka Powerful Tool**

**Concept:**
Lambda functions C++ mein inline functions banane ka tareeka hai jo aapko directly code mein hi chhote functions define karne deta hai. Ye aapko STL algorithms (jaise `sort`, `for_each`) ya custom callbacks ke liye functions define karne mein madadgar hote hain. Inka syntax `[capture](parameters) -> return_type { body }` hota hai.

**Example:**
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> nums = {5, 2, 8, 1, 3};

    // Lambda to sort in descending order
    std::sort(nums.begin(), nums.end(), [](int a, int b) {
        return a > b;
    });

    // Lambda to print each element
    std::for_each(nums.begin(), nums.end(), [](int n) {
        std::cout << n << " ";
    });

    return 0;
}
```
Output: `8 5 3 2 1`

**Practice:**
Ek lambda function likhein jo do integers ko multiply kare aur use `std::for_each` ke saath ek vector `numbers = {2, 4, 6, 8}` par apply kare.
