# Day 7 — **Short-Form Ka Magic: Viral Reels/Shorts Banane Ki 5 Golden Rules**

**Concept:**
Short-form content (Reels/Shorts) ka raaz hai **fast pacing, strong hook pehle 3 seconds, aur visually engaging elements**. Ismein **trendy transitions, text overlays, aur quick cuts** ka istemal hota hai. CapCut/Premiere mein **speed adjustments, keyframing, aur auto-captioning** jaise tools help karte hain.

**Example:**
Ek **food Reel** banane ke liye:
1. **Hook:** Pehle 3 seconds mein ek dramatic zoom-in ya "Wait for it..." text add karo.
2. **Pacing:** Har clip 1-2 seconds ka rakho, fast cuts ke liye **speed 1.5x-2x** use karo.
3. **Effect:** "Zoom-in" transition ya "Glitch" effect add karo.
4. **Caption:** Auto-captioning se dialogue add karo + bold text highlight karo.

**Practice:**
Apne phone se **30-second ka ek Reel shoot karo** (ya existing footage use karo). CapCut mein:
- Pehle 3 seconds mein ek **strong visual ya text** add karo.
- **Speed 1.5x** par set karo.
- **1-2 transitions** (e.g., zoom ya slide) add karo.

**Mini Project:**
Ek **trending audio** (jaise "Oh no, oh no, oh no no no" ya "It's giving...") par **30-second ka Reel edit karo**—hook, fast cuts, aur captioning use karke.

**Answer Key:**
hook text, 1.5x speed, zoom transition, auto-caption
