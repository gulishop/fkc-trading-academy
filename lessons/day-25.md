# Day 25 — Error Handling (Galat Input Sambhalna)

- **Concept:** `try-except` se program crash hone se bachana
- **Example:**
  ```python
  try:
      amount = float(input("Amount: "))
  except ValueError:
      print("Sahi number likhein!")
  ```
- **Practice:** Amount input mein error handling lagwayen
- **Mini Project:** "Safe Input Ledger"
