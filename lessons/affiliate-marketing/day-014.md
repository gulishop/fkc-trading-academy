# Day 14 — **Affiliate Links Ko "No-Follow" Ya "Sponsored" Karne Ka Sahi Tarika**

**Concept:**
Google aur FTC (Federal Trade Commission) ke rules ke mutabiq, affiliate links ko ya to "no-follow" ya "sponsored" karna zaroori hai. Aise links SEO ko negatively affect nahi karte aur legal bhi rehte hain. Yeh step affiliate marketing ko transparent rakhta hai aur trust build karne mein madad karta hai.

**Example:**
Ek blog post mein affiliate link lagate waqt, HTML code mein `rel="sponsored"` ya `rel="nofollow"` add karo:
`<a href="https://example.com/product" rel="sponsored">Buy Now</a>`
WordPress users ke liye, "Link" option mein "Sponsored" checkbox select karo.

**Practice:**
Apne kisi existing affiliate link ko edit karke usko "sponsored" ya "no-follow" mark karo. Check karo ki woh sahi tarike se apply hua hai.

**Mini Project:**
Ek simple blog post ya social media caption likhein jismein 2-3 affiliate links hon, sabhi ko "sponsored" ya "no-follow" ke saath format karo. Post ko publish karne se pehle validate karo.

**Answer Key:**
sponsored, no-follow, SEO-friendly, FTC-compliant
