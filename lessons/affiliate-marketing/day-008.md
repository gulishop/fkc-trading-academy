# Day 8 — **Affiliate Earnings Ka Hisaab: Aapki Har Link Ka ROI Nikalein**

**Concept:**
Har affiliate link ka performance track karna zaroori hai—kaunsi link kitni sales la rahi hai, kaunse traffic source se sabse zyada conversions ho rahe hain, aur kaunse content types behtar kaam kar rahe hain. Iske bina aap apne efforts ko optimize nahi kar sakte. Google Analytics 4 (GA4) aur affiliate networks ke built-in dashboards (jaise Amazon Associates ka "Reports" section) se aapko yeh data milta hai. Key metrics: **Click-Through Rate (CTR), Conversion Rate, Average Order Value (AOV), aur Earnings Per Click (EPC)**.

**Example:**
Maana aapne ek blog post "2024 ke Best Budget Smartphones" likha hai aur usme 3 affiliate links hain:
1. **Amazon** (₹15,000 ka smartphone)
2. **Flipkart** (₹16,000 ka same model)
3. **Daraz** (₹14,500 ka same model)

GA4 se pata chalta hai:
- Amazon link par **100 clicks** hue, **5 sales** hui (₹75,000 commission).
- Flipkart par **80 clicks**, **2 sales** (₹32,000 commission).
- Daraz par **120 clicks**, **3 sales** (₹43,500 commission).

**Practice:**
Apne kisi **ek affiliate link** (Amazon/Daraz/Flipkart) ka **CTR aur conversion rate** calculate karein:
1. GA4 ya network dashboard se **total clicks** aur **total sales** note karein.
2. **CTR = (Clicks / Impressions) × 100** (agar impressions available hain).
3. **Conversion Rate = (Sales / Clicks) × 100**.

**Mini Project:**
**10-minute audit:** Apne **sabse recent affiliate post** ke sabhi links ka performance check karein. Top 3 metrics note karein:
- Best performing link (highest EPC)
- Worst performing link (lowest CTR)
- Kya aapko koi pattern nazar aata hai? (e.g., price range, product type, placement)

**Answer Key:**
CTR, conversion rate, EPC, GA4
