# Day 3 — **Audacity Se Audio Record Karna: Step-by-Step Guide**

**Concept:**
Aaj hum seekhenge ke Audacity mein kaise professional-quality audio record kiya jata hai. Yeh software free hai aur beginner-friendly bhi. Sabse pehle apne mic ko setup karo, Audacity mein input source select karo, aur recording start karne se pehle levels check karo taake clipping na ho.

**Example:**
1. **Mic Setup:** Apne mic ko computer se connect karo (USB/XLR).
2. **Audacity Open Karo:** File > New par click karo.
3. **Input Source Select Karo:** Transport > Transport Options > Audio Device par jao aur apna mic choose karo (e.g., "Microphone (Realtek Audio)").
4. **Recording Levels Check Karo:** Apne mic ke samne normal volume mein bol kar dekho ke red line na chali jaye (yeh clipping hai).
5. **Record Start Karo:** Red "Record" button dabao aur script padhna shuru karo.

**Practice:**
Apne script (Day 2 se) ko Audacity mein record karo. 30 seconds ka audio nikalo aur check karo ke:
- Volume zyada na ho (clipping na ho)
- Background noise kam ho
- Apka tone clear ho

**Mini Project:**
Ek 1-minute ka "Introduction" audio record karo jisme aap apna naam, skills, aur voice-over services ke baare mein short introduction do. Audio ko .mp3 format mein save karo.

**Answer Key:**
Mic setup, Audacity open, input select, record levels check, record start
