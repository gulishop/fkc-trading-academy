# Day 17 — **Snapseed aur VSCO se Pro-Level Editing: Advanced Tools ka Istemal**

**Concept:**
Snapseed aur VSCO ke advanced tools (jaise Selective, Healing, Curves, Grain) ka istemal karke photos ko professional level par edit karna sikhaya jayega. In apps se color grading, details enhance karna aur unwanted elements remove karna seekhoge.

**Example:**
Ek portrait photo mein background se ek unwanted object remove karna hai:
1. Snapseed → *Tools* → *Healing* → Unwanted area par tap karke drag karo.
2. VSCO → *Edit* → *Selective* → Shadows/Hightlights adjust karke details badhao.

**Practice:**
Apni kisi photo ko Snapseed ya VSCO mein khol kar *Healing* ya *Selective* tool use karke koi 1 unwanted element remove karo.

**Mini Project:**
Ek photo ko Snapseed aur VSCO donon apps se edit karke compare karo—kaun sa app aapki photo ke liye better hai?

**Answer Key:**
Healing tool, Selective adjustments, unwanted object remove, comparison
