# Day 25 — **Photo Editing Secrets: Non-Destructive Workflow in Lightroom**

**Concept:**
Aaj hum Lightroom ke *non-destructive editing* ka concept samjhenge—yani original photo intact rakh kar edits apply karna. Isse aap baar-baar changes kar sakte hain bina quality lose kiye. Key tools: *Adjustment Brush, Graduated Filter, Radial Filter*, aur *Presets*.

**Example:**
Ek portrait edit karna hai. Pehle *Adjustment Brush* se sirf face par exposure +0.30 increase karo (dark areas bright karne ke liye). Phir *Graduated Filter* se background ko blur karo (sharpness -20). Sab changes original file ko touch kiye bina honge.

**Practice:**
Apne kisi photo ko Lightroom mein import karo. *Basic panel* se exposure +0.15 aur contrast +10 adjust karo. Phir *Adjustment Brush* se sirf sky ko dark karo (exposure -0.20).

**Mini Project:**
Ek photo lekar *non-destructive* edits apply karo:
1. *Basic panel* mein WB, exposure, contrast adjust karo.
2. *Graduated Filter* se horizon line par vignette lagao.
3. *Preset* apply karo, phir usko tweak karo.

**Answer Key:**
Exposure +0.15, Contrast +10, Sky Exposure -0.20
