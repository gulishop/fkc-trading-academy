# Day 18 — **No-Code se Paise Kamana: Freelancing ka Next Level (Portfolio & Pitching)**

**Concept:**
Freelancing mein sirf skills nahi, balki apne work ko bechein aur clients ko convince karne ka tareeqa bhi zaroori hai. Aaj seekhein ke kaise ek strong portfolio banaya jae, niche niche clients dhunde, aur apne no-code projects ko behtar tarike se pitch karke high-paying gigs hasil karein.

**Example:**
Ek student ne FlutterFlow se ek "Task Manager App" banaya. Usne portfolio ke liye:
1. **GitHub/GitLab** par code aur apk file upload ki.
2. **Loom** par 2-minute video banayi jo app ke features explain karti hai.
3. **Upwork** par gig likhte waqt keywords jaise "FlutterFlow Expert", "Custom App Builder" use kiye.
4. Client ko proposal mein likha: *"Maine aapke business ke liye ek task management app banaya hai jo 50% zyada efficient hai. Aapko sirf ₹15,000 mein mil sakta hai—agar aapko demo chahiye to main free 15-minute call par explain kar sakta/sakti hun."*

**Practice:**
Apne kisi bhi no-code project (website/app) ke liye ek **1-paragraph pitch** likhein jo aap Upwork/Fiverr par use kar sakte hain. Pitch mein project ka naam, technology, aur client ko milne wale benefits zaroor shamil karein.

**Mini Project:**
**"Portfolio Website in 30 Minutes"** — Framer/Webflow/Wix par ek simple portfolio banayein jisme:
- 3 no-code projects ke screenshots/links
- Ek "Hire Me" button jo aapki email/Upwork profile par redirect ho
- Ek "About Me" section jisme apne skills aur experience ka zikr ho

**Answer Key:**
Portfolio, GitHub, Loom, Upwork gig
