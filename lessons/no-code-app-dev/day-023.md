# Day 23 — **No-Code App Builders: FlutterFlow vs Glide – Kaunsa Choose Karen?**

**Concept:**
FlutterFlow aur Glide do popular no-code app builders hain jo beginners se intermediate users ke liye perfect hain. FlutterFlow Flutter-based apps banata hai (jaise native apps), jabki Glide spreadsheets (Google Sheets) se directly mobile/web apps generate karta hai. Aaj hum inke differences, use cases, aur kya banaya ja sakta hai samjhenge.

**Example:**
1. **FlutterFlow:** Agar aap ek food delivery app banana chahte hain (jaise Zomato), to FlutterFlow ke drag-and-drop UI se screens design kar sakte hain, Firebase se backend connect kar sakte hain, aur payment gateway (Stripe) integrate kar sakte hain.
2. **Glide:** Agar aap ek simple inventory management app banana chahte hain (jaise warehouse ka stock track karna), to Google Sheets mein data enter karen, aur Glide automatically usko mobile app mein convert kar dega.

**Practice:**
1. **FlutterFlow:** Apne phone ya laptop par FlutterFlow account banayein aur ek basic "To-Do List" app ka UI design karen (3 screens: login, list view, add task button).
2. **Glide:** Google Sheets mein ek simple "Books Collection" sheet banayein (columns: Book Name, Author, Status – Read/Unread) aur Glide se usko app mein convert karen.

**Mini Project:**
**"Restaurant Menu App"** (FlutterFlow ya Glide se):
- FlutterFlow: Menu categories, dish images, prices, aur order button ke saath ek app banayein.
- Glide: Google Sheets mein menu data enter karen aur Glide se app generate karen (QR code share karke users ko dikhaye).

**Answer Key:**
FlutterFlow: UI design, Firebase, Stripe, Flutter, native-like; Glide: Google Sheets, spreadsheets, simple apps, no coding
