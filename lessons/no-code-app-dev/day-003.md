# Day 3 — FlutterFlow aur Glide se App Banana: No-Code App Development Ka Aasan Rasta

**Concept:**
FlutterFlow aur Glide no-code app builders hain jo drag-and-drop interface se mobile apps banane mein madad karte hain. FlutterFlow Flutter-based apps banata hai (jabki isko no-code samajhna galat hai—yeh low-code hai), jabki Glide spreadsheets (Google Sheets) se directly mobile apps generate karta hai. Dono beginner-friendly hain aur app development ki complexity ko kam karte hain.

**Example:**
**Glide se ek simple task manager app banane ke steps:**
1. Google Sheets mein 3 columns banayein: `Task`, `Status`, `Due Date`.
2. [Glide Apps](https://www.glideapps.com/) par jaayein, "New App" > "From Google Sheets" select karen.
3. "Layout" mein "List" ya "Grid" view choose karen.
4. App ko customize karen (colors, icons, buttons add karen).
5. "Publish" par click karen aur app ka link ya QR code share karen.

**Practice:**
Apne Google Sheets mein ek simple "Grocery List" banayein (3 columns: `Item`, `Quantity`, `Purchased`). Phir Glide se usko ek mobile app mein convert karen. App ka preview dekhein aur ek screenshot lein.

**Mini Project:**
Ek **Weather App** banayein jo Google Sheets se weather data (City, Temperature, Condition) display kare. Steps:
1. Google Sheets mein 3 columns banayein: `City`, `Temperature (°C)`, `Condition`.
2. Glide par ek "Card" layout select karen.
3. App ko publish karen aur apne phone par test karen.

**Answer Key:**
Google Sheets data, Glide app generator, Card layout, Publish link
