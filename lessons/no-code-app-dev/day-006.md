# Day 6 — Client Project Ka Basic Structure: Kaise Shuru Karein?

**Concept:**
Har no-code project ek client ke liye hota hai, isliye uska structure clear hona chahiye. Pehle **requirements** (kya chahiye?), **scope** (kitna hai?), aur **deliverables** (kya milega?) define karo. Phir **timeline** (kitne din mein?), **payment** (kitne ka?), aur **communication** (kaise update deni hai?) set karo. Yeh sab clear hone se project smooth chalta hai.

**Example:**
Ek client ko ek **portfolio website** banana hai. Requirements: 5 pages, contact form, aur mobile-friendly. Scope: 3 din ka hai. Deliverables: Figma design + live website. Timeline: Monday se Wednesday. Payment: $200 advance, $300 baqi. Communication: Daily 10-minute call.

**Practice:**
Apne ek imaginary client ke liye **requirements, scope, aur deliverables** likho (3-4 lines mein). Example: "Client ko ek restaurant menu app chahiye, 2 screens, offline mode, 1 week mein deliver karna hai."

**Mini Project:**
Ek **1-page Google Form** banayein jisme client se project requirements poochhein (3-5 questions). Link share karke logon se fill karwayein.

**Answer Key:**
requirements, scope, deliverables, timeline
