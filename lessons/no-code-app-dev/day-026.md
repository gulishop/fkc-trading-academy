# Day 26 — **Client Project ka Scope & Deliverables: "Kya Dena Hai" aur "Kya Nahi"**

**Concept:**
Har no-code project ki success uske **clear scope** aur **defined deliverables** par depend karti hai. Aaj seekhein ke client se project lene se pehle kya poochna hai, kaise milestones set karne hain, aur final delivery mein kya include karna hai. "Scope creep" (extra kaam ka dhundh) se bachne ke liye boundaries set karna zaroori hai.

**Example:**
Ek client ko ek **Glide app** banana hai jo employees ki attendance track kare. Pehle pooch:
1. "App mein kya features honge?" (e.g., GPS check-in, leave requests)
2. "Kya existing data (Excel) import karni hai?"
3. "App ka design kitna customized hona chahiye?"
Deliverables define karen:
- Functional app (Glide)
- 1-page user guide (Notion)
- 30-minute training video (Loom)

**Practice:**
Apne ek imaginary client se **3 questions poochen** jo project scope clarify karne ke liye zaroori hain. Apni learning notes mein likh kar rakhein.

**Mini Project:**
Ek **Notion template** banayein jo client ko project deliver karne ke liye use ho sakta hai. Include karen:
- Project scope (1 paragraph)
- Milestones (timeline)
- Deliverables list (bullet points)
- Client approval section

**Answer Key:**
project scope, milestones, deliverables, client approval
