# Day 4 — **Airtable aur Notion: Apne Data ko Smart Banana**

**Concept:**
Airtable aur Notion no-code tools hain jo databases ko visual, user-friendly banate hain. Airtable spreadsheets aur databases ka combination hai (jaise Excel + Access), jabke Notion ek all-in-one workspace hai jisme notes, tasks, aur databases ek hi jagah manage hote hain. In tools se aap data organize kar sakte hain, formulas apply kar sakte hain, aur workflows automate kar sakte hain—bina coding ke!

**Example:**
1. **Airtable:** Apne online store ke products ka database banayein. Columns add karen: *Product Name, Price, Stock, Category*. Phir "Views" feature se alag-alag tarike se data dekh sakte hain (e.g., "Low Stock" view jisme stock < 10 ho).
2. **Notion:** Apne freelancing projects ko track karen. Ek database banayein jisme columns hon: *Project Name, Client, Deadline, Status (To-Do/In Progress/Done)*. Phir "Kanban Board" view se drag-and-drop se status update karen.

**Practice:**
1. **Airtable:** Ek simple "Book Library" database banayein jisme 3 columns hon: *Book Title, Author, Genre*. 3-5 entries add karen.
2. **Notion:** Ek "Daily Tasks" database banayein jisme columns hon: *Task, Priority (High/Medium/Low), Due Date*. 3 tasks add karen aur unhe priority ke hisaab se sort karen.

**Mini Project:**
**"Personal Finance Tracker"** (Airtable + Notion):
- **Airtable:** Ek "Expenses" database banayein jisme columns hon: *Date, Amount, Category (Food/Transport/Entertainment), Description*. Har roz ki expenses add karen.
- **Notion:** Ek "Monthly Budget" page banayein jisme har category ke liye allocated amount set karen aur expenses ko compare karen. Notion ke formulas use karen (e.g., `prop("Amount")`).
- **Bonus:** Airtable ke "Automation" feature se ek email alert set karen jab koi expense $50 se zyada ho.

**Answer Key:**
Airtable: Book Title, Author, Genre; Expenses, Amount, Category; Automation, Email Alert; Monthly Budget, Allocated Amount
