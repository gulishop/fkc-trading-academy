# Day 14 — **No-Code Automation: Zindagi Bana Dein "Robot" Banana Seekh Lo!**

**Concept:**
Database aur automation ka matlab hai apne no-code tools ko itna smart bana dena ke wo khud hi kaam karne lage. Airtable aur Notion ke alawa **Zapier** ya **Make (Integromat)** jaise tools use karke hum manual tasks ko automate kar sakte hain. Jaise: "Jab koi form submit kare to automatically email bhej do" ya "Excel sheet mein new entry aate hi Google Sheet update ho jaye".

**Example:**
Ek freelancer hai jo clients se orders le raha hai. Har order ke baad wo:
1. Google Form bharata hai (order details)
2. Airtable mein entry add hoti hai
3. Zapier detect karta hai "New entry in Airtable" → automatically email client ko "Thank you" bhejta hai
4. Notion task board update ho jata hai "Order #123 - Pending"

**Practice:**
Apne **Google Drive** mein ek folder banayein "No-Code Automation Test". Uske andar ek **Google Sheet** banayein jisme 3 columns ho: `Name`, `Email`, `Status`. Phir **Zapier** mein ek "Zap" create karein jo:
- Trigger: "New Google Sheet Row"
- Action: "Send Email" (apne hi email par test karo)

**Mini Project:**
Ek **automated lead tracker** banayein:
1. Google Form banayein (3 fields: Name, Email, Service)
2. Airtable mein ek table banayein "Leads" (same fields)
3. Zapier se connect karein: "New Google Form Submission → New Airtable Record"
4. Notion mein ek board banayein "Leads Pipeline" (To Do, In Progress, Done)
5. **Bonus:** Add karein "When Airtable status changes to 'Done', send WhatsApp message via Twilio"

**Answer Key:**
Google Sheet row add, Zapier trigger, Email send, Airtable update
