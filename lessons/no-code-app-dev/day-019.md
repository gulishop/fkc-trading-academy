# Day 19 — **No-Code SEO: Apni Website/App Ko Google Par Rank Karwayein**

**Concept:**
No-code websites/apps ko bhi SEO (Search Engine Optimization) ki zarurat hoti hai taake Google par visible rahein. Basics jaise keywords, meta tags, sitemap, aur speed optimization no-code tools (Framer/Webflow/Wix) par bhi apply hote hain. AI tools (jaise SurferSEO ya Framer AI) se keywords aur content optimization bhi kar sakte hain.

**Example:**
1. **Keyword Research:** Google Keyword Planner ya Ubersuggest se "best no-code tools" jaise keywords dhundhein.
2. **Meta Tags:** Framer/Webflow mein page settings mein "SEO Title" aur "Description" add karein (e.g., "Top 5 No-Code Website Builders - 2024 Guide").
3. **Sitemap:** Wix/Framer mein auto-generated sitemap enable karein taake Google crawl kar sake.

**Practice:**
Apni no-code website (ya ek dummy page) ke liye:
- 1 relevant keyword choose karein.
- Meta title aur description likhein (50-60 characters title, 150-160 characters description).
- Sitemap check karein (agar tool support karta ho).

**Mini Project:**
Ek no-code website (Framer/Webflow/Wix) banayein aur uske 3 pages (Home, About, Contact) ke liye SEO optimize karein. Google Search Console mein submit karein.

**Answer Key:**
keyword research, meta tags, sitemap, Google Search Console
