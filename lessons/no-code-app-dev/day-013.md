# Day 13 — **FlutterFlow vs Glide: App Banane ke 2 Best No-Code Tools**

**Concept:**
FlutterFlow aur Glide do popular no-code app builders hain jo beginners se lekar intermediate users ke liye perfect hain. FlutterFlow Flutter-based apps banata hai (jaise native apps), jabki Glide spreadsheets (Google Sheets/Excel) se directly mobile apps generate karta hai. Dono ka apna style hai—FlutterFlow zyada customization deta hai, jabki Glide zyada quick aur spreadsheet-based hai.

**Example:**
- **FlutterFlow:** Agar tum ek food delivery app banana chahte ho, toh FlutterFlow ke drag-and-drop UI se screens design kar sakte ho, Firebase se backend connect kar sakte ho, aur custom logic (jaise order tracking) add kar sakte ho.
- **Glide:** Agar tum ek simple inventory app banana chahte ho (jaise shop ke products track karna), toh Google Sheets mein data enter karo, Glide se app generate karo, aur real-time updates dekh sako.

**Practice:**
1. **FlutterFlow:** [FlutterFlow](https://flutterflow.io) par jao, ek naya project start karo, aur ek basic login screen design karo (2-3 buttons + text fields).
2. **Glide:** [Glide](https://glideapps.com) par jao, Google Sheets se ek dummy data (jaise "Product Name, Price, Stock") enter karo, aur usse ek basic app generate karo.

**Mini Project:**
**"Task Manager App" banayein:**
- **FlutterFlow:** Ek app banayein jisme users tasks add kar saken, complete kar saken, aur Firebase se data save ho.
- **Glide:** Ek Google Sheet banayein jisme "Task, Status, Due Date" ho, aur Glide se uska app banayein jo mobile par show ho.

**Answer Key:**
FlutterFlow: login screen, buttons, Firebase; Glide: Google Sheets, app generate
