# Day 12 — **No-Code Hosting: Apne Website Ko Live Karein (Framer/Webflow/Wix)**

**Concept:**
Har no-code website builder (Framer/Webflow/Wix) ka apna hosting system hota hai. Yeh hosting ka matlab hai ke aapka website internet par accessible ho raha hai. Aaj hum seekhenge ke kaise apne no-code project ko live karein, hosting ka basic concept samajhein, aur best practices follow karein.

**Example:**
1. **Framer:** Project publish karne ke baad, Framer aapko ek `.framer.app` subdomain deta hai (e.g., `myproject.framer.app`). Custom domain add karne ke liye, settings mein ja kar DNS records update karein.
2. **Webflow:** "Publish" button press karne par, Webflow hosting par deploy ho jata hai. Custom domain ke liye, hosting settings mein ja kar domain add karein aur DNS records ko point karein.
3. **Wix:** "Publish" button se website live hoti hai. Custom domain add karne ke liye, "Domains" section mein ja kar domain purchase ya connect karein.

**Practice:**
Apne kisi bhi no-code website builder (Framer/Webflow/Wix) mein ek simple page banayein aur use publish karein. Agar custom domain available hai, to use bhi add karein.

**Mini Project:**
Ek no-code website banayein (3-5 pages) aur use Framer/Webflow/Wix par live karein. Custom domain add karne ki koshish bhi karein (agar possible ho).

**Answer Key:**
publish button, hosting settings, custom domain, DNS records
