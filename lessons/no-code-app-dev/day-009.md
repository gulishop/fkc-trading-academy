# Day 9 — **No-Code SEO: Apne Website/App Ko Google Par Rank Karana**

**Concept:**
No-code websites/apps bhi SEO (Search Engine Optimization) ki madad se Google par rank kar sakte hain. SEO ka matlab hai apne content ko search engines ke liye optimize karna taake log tumhare project ko search karen to uska result aaye. Keywords, meta tags, aur fast loading speed SEO ke basic elements hain.

**Example:**
Framer/Webflow mein SEO settings mein jake apne page ka title, description, aur URL set karo. Jaise ek blog post ka title "Best No-Code Tools 2024" rakhne se Google usko relevant search results mein show karega.

**Practice:**
Apne Framer/Webflow project mein jake ek page ka SEO title aur description likho jo tumhare niche ke keywords ko cover kare.

**Mini Project:**
Ek simple blog post (3-4 paragraphs) banao jisme 3-4 relevant keywords use kiye gaye hon. Framer/Webflow mein publish karo aur check karo ki SEO settings sahi se set hain.

**Answer Key:**
Title, description, keywords, loading speed
