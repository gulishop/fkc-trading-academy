# Day 22 — **Landing Pages: No-Code Se High-Converting Pages Banana**

**Concept:**
Aaj hum landing pages banayenge — wo dedicated pages jo ek specific action (jaise "Sign Up" ya "Buy Now") ke liye design ki jati hain. No-code tools (Framer/Webflow/Wix) se aap inhe 30 minutes se bhi kam mein bana sakte hain. Landing pages ka goal hota hai visitors ko convert karna, isliye unhe simple, fast-loading aur visually appealing banana zaroori hai.

**Example:**
Ek fitness app ka landing page banana hai. Steps:
1. **Headline:** "30 Days Mein Banayein Apna Perfect Body" (bold, clear)
2. **Subheadline:** "AI-powered workout plans + nutrition guide — sirf ₹499 mein!"
3. **CTA Button:** "Free Trial Shuru Karein" (green button, prominent)
4. **Social Proof:** "10,000+ users ne apna goal achieve kiya" (testimonials section)
5. **Mobile-friendly:** Check karna hai ki page har device par theek dikhe.

**Practice:**
Apne laptop ya phone se **Framer** ya **Wix** open karein. Ek blank landing page create karein aur niche diye gaye elements add karein:
- Ek headline (apne business idea ke hisab se)
- Ek subheadline (value proposition)
- Ek CTA button (jaise "Get Started" ya "Learn More")
- Ek image/video (placeholder ya apni file upload karein)
- Ek simple form (jaise "Email address" field + "Submit" button)

**Mini Project:**
**"Portfolio Landing Page"** — Apna no-code portfolio website banayein jo sirf aapki skills aur projects dikhaye. Include karein:
1. Hero section (aapka intro + main heading)
2. Projects gallery (3-4 cards)
3. Contact form (name, email, message)
4. Footer (social links)
Use karein **Framer** (free tier) ya **Webflow** (starter plan).

**Answer Key:**
headline, subheadline, CTA button, mobile-friendly
