# Day 2 — Website Builders: Framer, Webflow aur Wix se Professional Website Banana

**Concept:**
Website builders jaise Framer, Webflow aur Wix no-code tools hain jo drag-and-drop interface ke zariye professional websites banane mein madad karte hain. Inme templates, animations aur hosting built-in hote hain, isliye coding ki zarurat nahi hoti. Ye platforms beginners se lekar intermediate users ke liye perfect hain.

**Example:**
1. **Wix:** Simple drag-and-drop se ek portfolio website banane ke liye:
   - Wix.com par jao aur "Create a Site" select karo.
   - Template choose karo (e.g., "Portfolio & CV").
   - Left panel se elements drag karke add karo (text, images, buttons).
   - "Publish" par click karo aur apni website ka link share karo.

2. **Webflow:** Advanced designs ke liye:
   - Webflow.com par signup karo.
   - "New Project" > "Blank" select karo.
   - Left panel se elements drag karke ek responsive navbar banayo.
   - Right panel se styles adjust karo (fonts, colors).
   - "Publish" par click karo.

**Practice:**
Apne liye ek simple 3-page website banane ka try karo (Home, About, Contact). Kisi bhi platform (Wix/Webflow/Framer) ka use kar sakte ho. Minimum 5 elements (text, image, button) add karo.

**Mini Project:**
Ek "Restaurant Menu" website banayo:
- Homepage par menu items ki list ho.
- About page par restaurant ki story ho.
- Contact page par location aur contact form ho.
- Sab pages ko navbar se link karo.
- Website ko mobile-friendly banao.

**Answer Key:**
Homepage, About page, Contact page, Navbar, Mobile-responsive
