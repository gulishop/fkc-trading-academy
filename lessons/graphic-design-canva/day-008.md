# Day 8 — **AI-Powered Design Hacks: Canva ke Smart Features**

**Concept:**
Canva ke AI tools se design process ko fast aur smart banaya ja sakta hai. **Magic Edit** (objects ko edit karein), **Magic Eraser** (background se unwanted elements remove karein), aur **Magic Design** (automatically templates generate karein) jaise features se beginners bhi professional-level designs bana sakte hain.

**Example:**
1. **Magic Edit** se kisi photo mein object add karne ke liye:
   - Photo upload karein → **Edit photo** → **Magic Edit** → naya object describe karein (e.g., "sunflowers in background").
   - AI automatically photo mein integrate kar dega.

2. **Magic Design** se presentation ke liye template generate karne ke liye:
   - **Create a design** → **Magic Design** → topic likhein (e.g., "Digital Marketing Plan").
   - Canva 3-4 relevant templates suggest karega.

**Practice:**
Apni ek purani photo lein aur **Magic Eraser** se background se ek unwanted object remove karein.

**Mini Project:**
Ek **Instagram post** design karein jisme:
- **Magic Design** se 3 templates mein se ek choose karein.
- **Magic Edit** se photo mein ek extra element add karein (e.g., coffee cup).
- **Brand colors** apply karein aur export karein.

**Answer Key:**
photo edit, background remove, object add, template select
