# Day 6 — **Infographics Banana: Data Ko Visual Story Mein Badalna**

**Concept:**
Infographics data, statistics ya complex information ko aasan, attractive visuals mein convert karte hain. Canva ke templates aur tools se aap professional infographics bana sakte hain jo presentations, social media ya reports mein use ho sakte hain. Aaj hum seekhenge ki kaise data ko engaging visuals mein badalna hai.

**Example:**
Ek simple "Social Media Usage 2024" infographic banane ke liye:
1. Canva mein "Infographic" template search karen.
2. Data add karen (e.g., "Instagram: 2B users, Facebook: 3B users").
3. Bar graphs, icons, aur colors use karen taake data clear ho.
4. Text ko concise rakhen (max 1 line per point).

**Practice:**
Ek 3-5 fact wali infographic banayein jo aapke college ya job ke topic par ho (e.g., "AI ka Future in Pakistan").

**Mini Project:**
Ek **1-page infographic** banayein jismein aapke favorite brand ke 5 key statistics (e.g., revenue, customers, growth) visual form mein present karen. Use aap apne portfolio mein add kar sakte hain.

**Answer Key:**
data visualization, icons, concise text, color hierarchy
