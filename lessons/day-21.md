# Day 21 — Menu System Banana

- **Concept:** User ko options dena (loop + if-else combine)
- **Example:**
  ```python
  while True:
      print("1. Add Transaction  2. View Balance  3. Exit")
      choice = input("Option chunein: ")
      if choice == "3":
          break
  ```
- **Practice:** Menu ke 3 options ka structure banwayen
- **Mini Project:** "Menu-driven Ledger Shell"
