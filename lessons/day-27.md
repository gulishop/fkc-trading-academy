# Day 27 — GUI ka Intro (Tkinter)

- **Concept:** Terminal se hat kar buttons/windows wala app
- **Example:**
  ```python
  import tkinter as tk
  window = tk.Tk()
  window.title("Mera Accounting App")
  label = tk.Label(text="Khush Amdeed!")
  label.pack()
  window.mainloop()
  ```
- **Practice:** Ek button aur ek text box add karwayen
