# Day 9 — **Excel Dashboards: Data Ko "Live" Report Mein Badalna**

**Concept:**
Excel dashboards ek hi screen par multiple charts, tables aur key metrics ko combine karke real-time insights provide karte hain. Aaj hum seekhenge kaise ek interactive dashboard banaya jaye jo data ko "live" report mein badal de. Iske liye PivotTables, Charts, Slicers aur conditional formatting ka combination use hoga.

**Example:**
1. Ek sales dataset se **PivotTable** banayein (Rows: Product Category, Values: Total Sales).
2. Us PivotTable se **Column Chart** create karen (Sales by Category).
3. **Slicer** add karen (Filter: Region ya Month).
4. Dashboard mein **KPI cards** (Total Sales, Avg Sale) add karen using formulas.
5. Sab elements ko align karen aur professional look dene ke liye **Page Layout** adjust karen.

**Practice:**
Apne Excel mein ek **simple sales dashboard** banayein:
- Ek PivotTable banayein jo **Monthly Sales by Product** show kare.
- Uske neeche ek **Line Chart** add karen jo trend dikhaye.
- Right mein ek **Slicer** add karen jo **Year** filter kare.
- Top par ek **KPI card** banayein jo **Total Sales** show kare.

**Mini Project:**
**"Company Performance Dashboard"**
- 3-4 sheets se data import karen (Sales, Expenses, Customer Feedback).
- Ek dashboard banayein jo:
  - **Top 5 Products by Revenue** (Bar Chart)
  - **Monthly Profit Trend** (Line Chart)
  - **Customer Satisfaction Score** (Gauge Chart)
  - **Region-wise Performance** (Pie Chart)
  - **Filters:** Quarter, Product Category
- Dashboard ko **professional look** dene ke liye themes aur colors use karen.

**Answer Key:**
PivotTable, Column Chart, Slicer, KPI Card, Line Chart
