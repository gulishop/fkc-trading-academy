# Day 7 — **Data Validation: Excel Ko "Smart" Banana**

**Concept:**
Data validation Excel ko "smart" banata hai—yeh ensure karta hai ke users sirf sahi format ya range ki values enter karain. Isse data entry errors kam hoti hain aur consistency banti hai. Common use cases: dropdown lists, number ranges, date restrictions, aur custom formulas.

**Example:**
1. **Dropdown list banana:**
   - Select cell (e.g., B2) → **Data** tab → **Data Validation** → **Allow: List** → **Source:** `Yes, No, Maybe` (comma-separated).
2. **Number range restrict karna:**
   - Select cell → **Data Validation** → **Allow: Whole number** → **Data: between** → **Minimum: 10, Maximum: 100**.

**Practice:**
Apni Excel sheet mein ek column "Product Category" banain. Usmein **Data Validation** use karke ek dropdown list add karen jismein yeh options hon: `Electronics, Clothing, Groceries, Furniture`.

**Mini Project:**
Ek **Employee Attendance Tracker** banain jismein:
- Column A: Employee Name (text)
- Column B: Attendance Status (dropdown: `Present, Absent, Leave`)
- Column C: Salary (sirf numbers 30000–100000 ke beech allow hon).

**Answer Key:**
Dropdown list, data validation, range restrict, error handling
