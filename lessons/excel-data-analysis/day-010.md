# Day 10 — **Freelance Kaam Dhoondne ke Liye Excel Skills Ka Use**

**Concept:**
Freelance marketplaces (Upwork, Fiverr, Freelancer) par Excel-based projects dhoondne ke liye apne skills ko showcase karna zaroori hai. Clients ko impress karne ke liye portfolio banana, proposals likhna, aur relevant gigs kaise dhundhna hai—yeh sab seekhaya jayega. Excel se freelance kaam karne ke liye "Data Entry," "Report Automation," aur "Dashboard Creation" jaise niches sabse zyada demand mein hain.

**Example:**
1. **Upwork par profile banaen:**
   - "Excel Data Analyst" ya "Excel Automation Specialist" title use karen.
   - Portfolio mein apne Day 9 ke dashboard ka screenshot add karen.
   - Skills section mein "Excel," "PivotTables," "Power Query," aur "Dashboard Design" add karen.
2. **Gig post karen:**
   - Title: *"I will create a dynamic Excel dashboard for your business reports"*
   - Description mein batayein ke aap kaise data clean karte hain, PivotTables se insights nikalte hain, aur automated reports bana sakte hain.

**Practice:**
Upwork ya Fiverr par jayein aur ek "Excel Data Entry" ya "Dashboard Creation" ka gig post karne ka draft likhein (3-4 lines ka description).

**Mini Project:**
Ek **3-slide PDF portfolio** banayein jismein:
1. Apna Excel dashboard screenshot (Day 9 ka).
2. Ek simple data cleaning ka before/after example (Day 4 se).
3. Ek PivotTable se nikalta hua insight (Day 6 se).

**Answer Key:**
Portfolio draft, gig description, PDF slides structure
