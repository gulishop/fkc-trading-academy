# Day 8 — **Power Query: Excel ka "Data Doctor"**

**Concept:**
Power Query Excel ka advanced tool hai jo data cleaning aur transformation ko 10x fast banata hai. Isse external files (CSV, Excel, databases) import karke automatically clean, filter, aur reshape kar sakte hain. No more manual copy-paste ya formulas—just "Get & Transform" se data ready ho jata hai.

**Example:**
1. **Data import:** File > Get Data > From File > From Excel. Apni Excel file select karo.
2. **Cleaning steps:**
   - Remove empty rows: Home > Remove Rows > Remove Blank Rows.
   - Replace text: Transform > Replace Values (e.g., "N/A" → "").
   - Split columns: Transform > Split Column > By Delimiter (e.g., comma-separated data).
3. **Load:** Close & Load → New sheet mein cleaned data aa jayega.

**Practice:**
Apni Excel file se ek CSV file import karo (ya download karo). Power Query se:
- Pehle 5 empty rows remove karo.
- "Unknown" values ko "" (khali) se replace karo.
- Ek column ko split karo jo comma (,) se separate hai.

**Answer Key:**
import CSV, remove blank rows, replace "Unknown", split by comma
