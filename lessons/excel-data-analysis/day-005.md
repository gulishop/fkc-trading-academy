# Day 5 — **Charts aur Graphs: Data ko Visual Story Banaana**

**Concept:**
Excel mein charts aur graphs se data ko visually represent karke insights nikalna seekhein. Bar charts, pie charts, line graphs, aur scatter plots ka istemal karke trends, comparisons, aur distributions ko samajhna aasan ho jata hai. Charts dynamic bhi hote hain—data update hone par yeh bhi automatically adjust hote hain.

**Example:**
1. **Bar Chart:** Monthly sales data ko compare karne ke liye:
   - Select data (e.g., months in column A, sales in column B).
   - Insert → Bar Chart → Clustered Bar.
   - X-axis par months, Y-axis par sales values dikhein.
2. **Pie Chart:** Market share ka breakdown:
   - Select categories (e.g., "Product A", "Product B") aur percentages.
   - Insert → Pie Chart → 2D Pie.
   - Har segment ka percentage aur label check karein.

**Practice:**
Apne Excel mein ek **line graph** banayein jo 2023 ke 4 quarters ki company revenue ko show kare. Data yeh ho:
| Quarter | Revenue |
|---------|---------|
| Q1      | 50,000  |
| Q2      | 75,000  |
| Q3      | 60,000  |
| Q4      | 90,000  |
