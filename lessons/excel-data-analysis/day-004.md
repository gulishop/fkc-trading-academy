# Day 4 — **Data Cleaning: Excel ka Secret Weapon**

**Concept:**
Excel mein "clean data" ka matlab hai: no extra spaces, correct formats, no duplicates, and consistent entries. Aaj hum seekhenge kaise formulas (`TRIM`, `CLEAN`, `SUBSTITUTE`) aur tools (`Find & Replace`, `Remove Duplicates`, `Text to Columns`) se messy data ko professional banaya jata hai. Clean data = accurate analysis = less headaches!

**Example:**
Ek Excel sheet mein "  John  " (extra spaces), "john.doe@email.com" aur "john doe@email.com" (inconsistent dots) hain. Steps:
1. `=TRIM(A1)` se extra spaces remove karo.
2. `=SUBSTITUTE(A2, ".", "")` se dots hatao.
3. `Data > Remove Duplicates` se duplicate emails nikaalo.

**Practice:**
Apne Excel mein ek column mein "  ali  ", "ali ", aur "ALI" likho. `TRIM` aur `UPPER`/`LOWER` formulas use karke sabko lowercase aur single space mein convert karo.

**Mini Project:**
Ek "dirty" dataset download karo (Google par "sample messy data Excel" search karo). Uske saath yeh karo:
- Extra spaces remove karo.
- Dates ko consistent format mein badlo (e.g., `dd-mm-yyyy`).
- Duplicate rows nikaalo.
- Final clean file save karo.

**Answer Key:**
TRIM, SUBSTITUTE, Remove Duplicates, Text to Columns
