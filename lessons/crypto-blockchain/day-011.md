# Day 11 — **Smart Contracts: Blockchain Ka Digital Lawyer**

**Concept:**
Smart contracts blockchain par automatically execute hone wale digital agreements hain. Inmein predefined rules likhe jaate hain, aur jab conditions fulfill hoti hain, to contract automatically complete ho jati hai—bina kisi third-party (jaise lawyer ya bank) ke. Ye trustless hote hain: ek baar deploy hone ke baad inhe koi change ya hack nahi kar sakta.

**Example:**
Imagine ek vending machine: tum ₹500 dalte ho, machine automatically tumhe chips de deti hai. Smart contract bhi aisa hi hai—tum "agar X condition hogi, to Y action execute ho" likh dete ho, aur blockchain ye automatically handle karti hai.

**Practice:**
1. **Remix IDE** (browser-based smart contract platform) open karo: https://remix.ethereum.org
2. "File Explorer" mein ek naya file banayo: `SimpleContract.sol`
3. Ye code paste karo:
   ```solidity
   // SPDX-License-Identifier: MIT
   pragma solidity ^0.8.0;
   contract SimpleStorage {
       uint storedData;
       function set(uint x) public {
           storedData = x;
       }
       function get() public view returns (uint) {
           return storedData;
       }
   }
   ```
4. "Compile" button dabayo, phir "Deploy" karo (Injected Web3 ya "Remix VM" select karo).

**Mini Project:**
