# Day 4 — **Smart Contracts: Blockchain Ka Magic Trick**

**Concept:**
Smart contracts blockchain par automatically chalne wale programs hain jo predefined rules ke mutabiq kaam karte hain. Inhe koi third party ya lawyer ki zaroorat nahi hoti—bas code trust karta hai. Ethereum inhe support karta hai, lekin ab toh almost har blockchain inka istemal karti hai.

**Example:**
Imagine ek vending machine: tum paise dalte ho, machine automatically tumhe snack deti hai. Smart contract bhi aise hi hai—agar tumne 1 ETH bheja, toh wo automatically tumhe NFT ya token bhej dega, bina kisi middleman ke.

**Practice:**
Apne MetaMask wallet mein "Add Token" karke ek popular token (jaise USDC ya SHIB) ka address paste karke add karo. (Token ka address Google se search kar sakte ho.)

**Mini Project:**
Ek simple smart contract banane ka try karo (agar interest ho toh):
1. Remix IDE (remix.ethereum.org) open karo.
2. "Create New File" > naam do "SimpleStorage.sol".
3. Ye code paste karo:
   ```solidity
   // SPDX-License-Identifier: MIT
   pragma solidity ^0.8.0;
   contract SimpleStorage {
       uint storedData;
       function set(uint x) public {
           storedData = x;
       }
       function get() public view returns (uint) {
           return storedData;
       }
   }
   ```
4. "Compile" > "Deploy" karke contract deploy karo.

**Answer Key:**
MetaMask, USDC/SHIB address, Remix IDE, SimpleStorage.sol
