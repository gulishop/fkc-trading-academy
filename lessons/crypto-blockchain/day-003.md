# Day 3 — **Crypto Wallet Secure Karna: Apne Digital Assets Ki Hifazat**

**Concept:**
Crypto wallet ek digital "bank account" hai jo aapki coins/tokens ko store karta hai. Lekin yeh traditional bank se alag hai—iske private keys (secret passwords) sirf aapke paas hote hain. Agar yeh keys chori ho gayin ya bhool gaye, toh aapki crypto permanently kho jati hai. Isliye security sabse zaroori hai!

**Example:**
Imagine a wallet with 2 keys:
- **Public Key** (Address): Jaise ATM card number (share kar sakte hain).
- **Private Key** (Secret Password): Jaise ATM PIN (kisi ko bhi mat batana!).
Agar koi private key hack ho jata hai, toh sab khatam.

**Practice:**
Apne phone ya laptop par **Trust Wallet** ya **MetaMask** install karein. Ek naya wallet create karein aur **12-word seed phrase** ko safely likh kar rakhein (kisi ko bhi share mat karein!).

**Mini Project:**
Apne wallet ka **test transaction** karein:
1. Wallet create karein.
2. Kisi dost se 0.001 BTC ya ETH bhejne ko kahen.
3. Transaction confirm hone ka wait karein aur apne wallet mein check karein.
