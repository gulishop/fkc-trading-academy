Day 2 — Blogger vs WordPress: Apna Blog Kaise Setup Karen? (Step-by-Step Guide) Concept. Aaj hum apna blog Blogger ya WordPress par setup karna seekhenge. Blogger free hai (Google ka platform), lekin WordPress zyada flexible hai (hosting khud ki lena hoti hai). Har ek ke pros-cons samajh kar decide karna zaroori hai. Blogger Setup (5 min mein). 1. Google account se blogger.com par jao. 2. "New Blog" par click karo, title (e.g., "Urdu Tech Tips"), address (e.g., urdutechtips.blogspot.com) enter karo. 3. Template choose karo (simple "Contempo" ya "Soho"). 4. "Create blog!" par click karo. Done! WordPress Setup (15 min mein). 1. Hosting khareedo (e.g., Bluehost, Hostinger) — ₹2000/month se shuru. 2. Domain register karo (e.g., urdutechtips.com). 3. WordPress install karo (hosting ke cPanel se "1-click install" option use karo). 4. Login karo, theme install karo (e.g., "Astra" ya "GeneratePress"). 5. Pages (Home, About) aur first post likh kar publish karo. Practice. Apna ek blog Blogger ya WordPress par setup karo (agar WordPress choose karte hain to hosting khareedne ki zaroorat hai). Mini Project. Apne blog ka Homepage design karo — 1-2 sections add karo (e.g., "Latest Posts" widget ya "About Me" section).
