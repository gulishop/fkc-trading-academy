Day 1 — C++ سیٹ اپ اور 'Hello World' پروگرام تصورات. آج ہم C++ پروگرامنگ شروع کرنے سے پہلے اپنے سسٹم پر C++ کمپائلر اور IDE (انٹیگریٹڈ ڈویلپمنٹ ماحول) سیٹ اپ کریں گے۔ کمپائلر کوڈ کو مشین لینگویج میں ترجمہ کرتا ہے، جبکہ IDE کوڈنگ، ڈیبگنگ اور رننگ کو آسان بناتا ہے۔ پہلا پروگرام 'Hello World' کہلاتا ہے—یہ پروگرامنگ کی ابتدائی نشانی ہوتی ہے۔ مثال. 1. کمپائلر انسٹال کریں: - Windows: MinGW-w64 ڈاؤن لوڈ کریں (یا MSYS2)۔ - Mac: ٹرمینل میں xcode-select --install رن کریں۔ - Linux: sudo apt install g++ (اوبنٹو/ڈیبین) یا sudo dnf install gcc-c++ (فیڈورا)۔ 2. IDE انسٹال کریں: - VS Code (ہلکا پھلکا، ایکسٹینشنز: 'C/C++' اور 'Code Runner')۔ - یا Code::Blocks (سادہ IDE)۔ 3. پہلا پروگرام لکھیں: - g++ hello.cpp -o hello سے کمپائل کریں۔ - ./hello (لِنکس/میک) یا hello.exe (ونڈوز) سے رن کریں۔ مشق. اپنے سسٹم پر C++ کمپائلر اور VS Code سیٹ اپ کریں، اور اوپر والا 'Hello World' پروگرام رن کریں۔ اسکرین شاٹ یا ٹرمینل آؤٹ پٹ شیئر کریں۔
