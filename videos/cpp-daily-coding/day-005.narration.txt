Day 5 — Arrays: Ek Se Zyada Data Ko Store Karna Concept. Arrays ek hi type ke multiple values ko store karne ka tareeka hai. Jaise 5 students ke marks store karne hain, to ek array banayenge marks[5] — har index par ek mark. Arrays se code sath mein manage hota hai aur loops ke saath bohat kaam aata hai. Example. Yeh 5 students ke marks print karega. Practice. Ek array numbers[10] banayein jo 1 se 10 tak numbers store kare. Phir ek loop chalayein jo sab numbers ko print kare aur unka sum bhi calculate kare. Mini Project. Even/Odd Counter Ek array arr[10] mein 10 random numbers store karayein (1-100 ke beech). Phir ek program likhein jo: 1. Array ke har element ko print kare. 2. Count kare ke kitne even numbers hain aur kitne odd. 3. Sabse bade aur sabse chhote number ko bhi print kare.
