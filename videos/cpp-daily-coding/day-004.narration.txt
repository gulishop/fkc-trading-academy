Day 4 — Loops: Bar-Bar Karo Code Ko Repeat Concept. Loops ka istemal tab hota hai jab aapko ek hi code block ko baar-baar chalana ho. for, while, aur do-while loops ke zariye aap repetitive tasks automate kar sakte hain. for loop tab best hai jab aapko pehle se pata ho kitni baar repeat karna hai, jabki while loop tab use hota hai jab condition pehle se maloom na ho. Example. Ek program banao jo 1 se 5 tak numbers print kare: Output: 1 2 3 4 5 Practice. Ek program likho jo user se ek number input le aur uske table (1 se 10 tak) ko print kare. (Hint: while loop use karo) Mini Project. Ek simple calculator banao jo user se do numbers aur ek operator (+, -, , /) input le, phir loop ke zariye result calculate kare aur bar-baar chalne de jab tak user "exit" na type kare.
