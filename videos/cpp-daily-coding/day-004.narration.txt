Day 4 — Loops: Bar-Bar Karo Code Ko Repeat Aaj hum loops ke baare mein seekhenge. Loops ka istemal tab hota hai jab aapko ek hi code block ko baar-baar chalana ho. Inke zariye aap repetitive tasks ko automate kar sakte hain, jisse aapka time aur mehnat bachti hai. Hum for, while, aur do-while loops ke baare mein detail se jaanenge aur samjhenge ke har loop ka istemal kab aur kaisa hota hai. Concept. Loops ka concept programming mein bahut zaroori hai. Jab aapko ek hi tareeqe ka code baar-baar chalana ho, tab loops ka istemal hota hai. Teen main types ke loops hote hain: for, while, aur do-while. for loop tab best hota hai jab aapko pehle se pata ho ke kitni baar repeat karna hai, jaise ke ek array ke har element ko print karna. while loop tab use hota hai jab aapko condition check karni ho aur jab tak wo condition true ho, tab tak loop chalana ho. do-while loop mein pehle loop chalaya jata hai phir condition check ki jati hai, isliye yeh guarantee deta hai ke loop kam se kam ek baar to chalega hi. Example. Chalo ek simple program dekhte hain jo 1 se 5 tak numbers print kare. Yeh for loop ka istemal karke kiya gaya hai: Is program ka output yeh hoga: 1 2 3 4 5 Yeh dekhne mein chhota lagta hai, lekin isse pata chalta hai ke kaise ek loop ka istemal karke repetitive task ko automate kiya ja sakta hai. Practice. Ab aap ek program likhiye jo user se ek number input le aur uske table (1 se 10 tak) ko print kare. Yeh while loop ka istemal karke kiya ja sakta hai.
