Day 3 — آپریٹرز اور ٹائپ کنورژن: اپنے پروگرامز کو اور پاورفل بنانا C++ میں آپریٹرز اور ٹائپ کنورژن کا استعمال پروگرامز کو زیادہ طاقتور اور لچکدار بناتا ہے۔ آپریٹرز کی مدد سے ہم حسابات اور فیصلے کرتے ہیں، جبکہ ٹائپ کنورژن سے مختلف ڈیٹا ٹائپس کو آپس میں تبدیل کر کے کوڈ کو مزید موثر بنایا جا سکتا ہے۔ Concept. C++ میں آپریٹرز حسابات اور فیصلے کرنے کے لیے استعمال ہوتے ہیں (جیسے +، -، ، /، %، ==، !=، &&، ||)۔ ٹائپ کنورژن کا مطلب ہے ایک ڈیٹا ٹائپ کو دوسرے میں تبدیل کرنا (جیسے int کو float میں)۔ یہ سب پروگرامنگ کو لچکدار اور موثر بناتا ہے۔ Example. include <iostream using namespace std; int main() { int a = 5, b = 2; float result = a / b; // Implicit conversion (int/float → float) cout << "تقسیم: " << result << endl; // Output: 2.5 // Explicit conversion (C-style) int x = 10; float y = (float)x / 3; // Output: 3.333... cout << "مخصوص کنورژن: " << y << endl; return 0; } Practice. ایک پروگرام لکھیں جو صارف سے 2 نمبرز ان پٹ لے اور ان کا: 1. جمع (int) 2. اوسط (float، 2 ڈیسیمل جگہوں تک) 3. باقی ماندہ (ماڈیولس آپریٹر استعمال کرتے ہوئے) کا حساب لگائے۔ Mini Project. "سادہ کیلکولیٹر" — صارف سے 2 نمبرز اور ایک آپریٹر (+، -، ، /) ان پٹ لو، پھر نتیجہ حساب کر کے دکھائیں۔ ٹائپ کنورژن کا استعمال کرتے ہوئے ڈیسیمل نتائج کو بھی ہینڈل کریں۔
