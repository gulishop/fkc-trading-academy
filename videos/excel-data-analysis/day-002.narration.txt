Day 2 — AVERAGE aur COUNTIF: Data ko samajhne ke liye zaroori functions Concept. Aaj hum AVERAGE aur COUNTIF functions seekhenge jo data ko analyze karne mein madad karte hain. AVERAGE kisi range ke numbers ka mean nikalta hai, jabki COUNTIF kisi condition ke hisaab se cells count karta hai (jaise "kitne students ne 80+ marks liye"). Ye functions data ko summarize karne ke liye bohat useful hain. Example. 1. AVERAGE. =AVERAGE(B2:B10) — Excel sheet mein cells B2 se B10 tak ke numbers ka average calculate karega. 2. COUNTIF. =COUNTIF(C2:C10, " 50") — Column C mein 50 se zyada values wali cells count karega. Practice. Ek Excel file mein ek column mein 10 students ke marks hain (50, 65, 72, 80, 45, 90, 78, 60, 85, 55). Inke liye: 1. AVERAGE function use karke sabka average marks nikalho. 2. COUNTIF use karke kitne students ke 70+ marks hain, count karho. Mini Project. Ek small Excel sheet banayo jismein ek column mein 15 employees ke salaries hain (50000, 60000, 75000, 80000, 45000, 90000, 65000, 70000, 55000, 85000, 72000, 68000, 95000, 52000, 78000). Inke liye: 1. Average salary calculate karo. 2. Kitne employees ki salary 70000 se zyada hai, count karo. 3. Kitne employees ki salary 50000 se kam hai, count karo.
