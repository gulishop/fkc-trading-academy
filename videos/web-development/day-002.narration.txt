Day 2 — CSS Basics: Apni Pehli Styling Karna Concept. CSS (Cascading Style Sheets) se hum HTML elements ko rang, size, aur position dete hain. Aaj hum selectors, colors, fonts, aur basic layout (margins, padding) seekhenge. Yeh HTML structure ko visually attractive banata hai. Example. 1. index.html mein <h1 Hello World</h1 likho. 2. style.css file banayo aur link karo: 3. CSS mein: Practice. Apne h1 ko red color, 32px font size, aur center align karo. Mini Project. Ek simple webpage banayo jisme: - 1 <h1 heading (text: "Mera Pehla CSS Page") - 1 <p paragraph (text: "Yeh mera CSS practice hai!") - 1 <button ("Click Me") Styling karo: heading green, paragraph italic, button blue background.
