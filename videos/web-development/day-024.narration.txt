دن ۲۴ — بیک اینڈ کی بنیادیات کا تعارف: اے پی آئیز اور سرور سائیڈ پروگرامنگ تصور. آج ہم بیک اینڈ ڈویلپمنٹ کی بنیادیات سیکھیں گے۔ بیک اینڈ سرور پر چلتا ہے جو فرنٹ اینڈ (ایچ ٹی ایم ایل/سی ایس ایس/جے ایس) سے ریکوئسٹس قبول کرتا ہے اور رسپونسز بھیجتا ہے۔ اے پی آئیز (ایپلیکیشن پروگرامنگ انٹرفیسز) بیک اینڈ اور فرنٹ اینڈ کے درمیان کمیونیکیشن کا پل ہوتی ہیں۔ ہم Node.js اور Express.js کا استعمال کرتے ہوئے ایک سادہ اے پی آئی بنائیں گے جو ڈیٹا بھیجے اور وصول کرے گی۔ مثال. ایک سادہ ایکسپریس سرور بنانے کے مراحل: ۱۔ ٹرمینل میں npm init -y اور npm install express چلائیں۔ ۲۔ server.js فائل بنائیں: ۳۔ ٹرمینل میں node server.js چلائیں اور براؤزر میں http://localhost:3000/api/greet کھولیں۔ پریکٹس. اپنے ایکسپریس سرور میں ایک /api/time اینڈ پوائنٹ شامل کریں جو موجودہ وقت واپس کرے۔ (اشارہ: new Date() کا استعمال کریں) منی پروجیکٹ. ایک سادہ ریسٹ اے پی آئی بنائیں جو GET /api/books اور POST /api/books اینڈ پوائنٹس سپورٹ کرے۔ ہر کتاب کا آبجیکٹ { id, title, author } فارمیٹ میں ہو۔
