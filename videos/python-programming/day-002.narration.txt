Day 2 — Variables, Data Types aur Input/Output Concept. Variables Python mein boxes ki tarah hain jinme hum data store karte hain. Har variable ka ek data type hota hai (jaise number, text, ya boolean). Input/output ka matlab hai program aur user ke beech communication—user se data lena (input) aur results show karna (output). Example. Practice. Ek program likhein jo user se 2 numbers input le, unko add karke result print kare. Mini Project. Ek simple calculator banayein jo user se 2 numbers input le aur unke liye +, -, , / operations perform kare.
