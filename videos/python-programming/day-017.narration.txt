دن 17 — JSON ڈیٹا کے ساتھ کام کرنا: پڑھنا، لکھنا، اور پارس کرنا تصور. JSON (جاوا اسکرپٹ آبجیکٹ نوٹیشن) ایک ہلکا پھلکا ڈیٹا فارمیٹ ہے جو ہر جگہ استعمال ہوتا ہے—APIs، کنفیگ فائلز، اور ڈیٹا اسٹوریج۔ پائتھن کا بلٹ ان json ماڈیول آپ کو پائتھن ڈکشنریز کو JSON اسٹرنگز (json.dump()/json.dumps()) میں اور واپس (json.load()/json.loads()) تبدیل کرنے دیتا ہے۔ یہ ویب ایپس، APIs، اور کنفیگ مینجمنٹ کے لیے نہایت ضروری ہے۔ مثال. مشق. 3 کلید-قیمت (key-value) کے جوڑوں والی ایک ڈکشنری بنائیں (مثلاً {"book": "Python Crash Course", "author": "Eric Matthes", "year": 2019})۔ اسے book.json میں محفوظ کریں اور پھر مصنف کا نام پرنٹ کرنے کے لیے اسے دوبارہ پڑھیں۔ منی پروجیکٹ. ایک سادہ کانٹیکٹ بک بنائیں جو: 1. صارف کا ان پٹ (نام، فون، ای میل) لے اور اسے contacts.json میں محفوظ کرے۔ 2. صارفین کو نام کے ذریعے رابطہ تلاش کرنے اور ان کی تفصیلات دکھانے کی سہولت فراہم کرے۔
