دن ۲۱ — Python پیکجز اور pip: لائبریریز انسٹال اور مینج کرنا تصور. Python میں لائبریریز (پیکجز) انسٹال کرنے کے لیے pip (Package Installer for Python) استعمال ہوتا ہے۔ یہ ایک کمانڈ لائن ٹول ہے جو بیرونی لائبریریوں کو ڈاؤن لوڈ اور انسٹال کرتا ہے۔ ہر Python پروجیکٹ میں ڈیپینڈینسیز سنبھالنے کے لیے pip لازمی ہے۔ آج ہم سیکھیں گے کہ کس طرح pip استعمال کر کے لائبریریز انسٹال کرنی ہیں اور انہیں اپنے کوڈ میں امپورٹ کرنا ہے۔ مثال. ۱۔ - pip ورژن چیک کرنا: ٹرمینل/کمانڈ پرامپٹ میں یہ کمانڈ چلائیں: اگر انسٹال ہے تو ورژن ظاہر ہوگا، نہیں تو ایرر آئے گا۔ ۲۔ - لائبریری انسٹال کرنا: ایک مقبول لائبریری requests انسٹال کرنے کے لیے: ۳۔ - لائبریری استعمال کرنا: Python فائل میں: مشق. اپنے سسٹم پر pip چیک کرنے کے بعد، ایک اور لائبریری python-dotenv انسٹال کریں اور تصدیق کریں کہ وہ کامیابی سے انسٹال ہو چکی ہے۔ منی پروجیکٹ. ایک چھوٹا پروجیکٹ بنائیں جو: ۱۔ pip سے requests لائبریری انسٹال کرے۔ ۲۔ GitHub API سے پبلک ریپوزیٹریز کی فہرست حاصل کرے۔ ۳۔ پہلی ۵ ریپوزیٹریز کے نام پرنٹ کرے۔
