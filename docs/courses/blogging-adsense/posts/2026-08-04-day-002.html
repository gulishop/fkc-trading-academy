Day 2 — **Blogger vs WordPress: Apna Blog Kaise Setup Karen? (Step-by-Step Guide)**

Concept

Aaj hum apna blog **Blogger** ya **WordPress** par setup karna seekhenge. Blogger free hai (Google ka platform), lekin WordPress zyada flexible hai (hosting khud ki lena hoti hai). Har ek ke pros-cons samajh kar decide karna zaroori hai.

Example

Blogger Setup (5 min mein)

1. Google account se [blogger.com](https://blogger.com) par jao.
2. "New Blog" par click karo, title (e.g., "Urdu Tech Tips"), address (e.g., `urdutechtips.blogspot.com`) enter karo.
3. Template choose karo (simple "Contempo" ya "Soho").
4. "Create blog!" par click karo. Done!

WordPress Setup (15 min mein)

1. Hosting khareedo (e.g., Bluehost, Hostinger) — ₹2000/month se shuru.
2. Domain register karo (e.g., `urdutechtips.com`).
3. WordPress install karo (hosting ke cPanel se "1-click install" option use karo).
4. Login karo, theme install karo (e.g., "Astra" ya "GeneratePress").
5. Pages (Home, About) aur first post likh kar publish karo.

Practice

Apna ek blog **Blogger ya WordPress** par setup karo (agar WordPress choose karte hain to hosting khareedne ki zaroorat hai).

Mini Project

Apne blog ka **Homepage design** karo — 1-2 sections add karo (e.g., "Latest Posts" widget ya "About Me" section).

تصور

آج ہم اپنا بلاگ **بلاگر** یا **ورڈپریس** پر سیٹ اپ کرنا سیکھیں گے۔ بلاگر مفت ہے (گوگل کا پلیٹ فارم)، لیکن ورڈپریس زیادہ لچک دار ہے (ہوسٹنگ خود لینی ہوتی ہے)۔ ہر ایک کے فائدے اور نقصانات سمجھ کر فیصلہ کرنا ضروری ہے۔

مثال

بلاگر سیٹ اپ (5 منٹ میں)

1. گوگل اکاؤنٹ سے [blogger.com](https://blogger.com) پر جائیں۔
2. "نیا بلاگ" پر کلک کریں، ٹائٹل (مثلاً "اردو ٹیک ٹپس")، ایڈریس (مثلاً `urdutechtips.blogspot.com`) انٹر کریں۔
3. ٹیمپلیٹ چن لیں (سادہ "Contempo" یا "Soho")۔
4. "بلاگ بنائیں!" پر کلک کریں۔ ہو گیا!

ورڈپریس سیٹ اپ (15 منٹ میں)

1. ہوسٹنگ خریدو (مثلاً Bluehost، Hostinger) — ₹2000/ماہ سے شروع۔
2. ڈومین رجسٹر کرو (مثلاً `urdutechtips.com`)۔
3. ورڈپریس انسٹال کرو (ہوسٹنگ کے cPanel سے "1-click install" آپشن استعمال کرو)۔
4. لاگ ان کرو، تھیم انسٹال کرو (مثلاً "Astra" یا "GeneratePress")۔
5. پیجز (ہوم، اباؤٹ) اور پہلا پوسٹ لکھ کر پبلش کرو۔

مشق

اپنا ایک بلاگ **بلاگر یا ورڈپریس** پر سیٹ اپ کرو (اگر ورڈپریس چننے کا ارادہ ہے تو ہوسٹنگ خریدنے کی ضرورت ہے)۔

مینی پراجیکٹ

اپنے بلاگ کا **ہوم پیج ڈیزائن** کرو — 1-2 سیکشنز ایڈ کرو (مثلاً "تازہ ترین پوسٹس" وِجٹ یا "مجھے بارے میں" سیکشن)۔
