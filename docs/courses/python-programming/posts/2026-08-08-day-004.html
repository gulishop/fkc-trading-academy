Day 4 — Lists, Tuples aur Dictionaries: Data Structures ka Power

↩️ Pichla lesson: Day 3 — If-Else aur Loops: Program Flow Control — aaj is se aage badhte hain.

🎬 AI Video Explanation

Concept

Lists, tuples aur dictionaries Python ke fundamental data structures hain jo multiple items ko store karte hain. Lists ordered aur mutable hoti hain (changeable), tuples ordered aur immutable (unchangeable), jabki dictionaries key-value pairs store karte hain. Inke zariye aap complex data ko organize aur manipulate kar sakte hain.

Example

# List example
fruits = ["apple", "banana", "cherry"]
fruits.append("orange")  # List mein add
print(fruits[1])  # Output: banana

# Tuple example
colors = ("red", "green", "blue")
print(colors[0])  # Output: red

# Dictionary example
student = {"name": "Ali", "age": 20, "grade": "A"}
print(student["name"])  # Output: Ali

Practice

Ek list `numbers` banayein jismein 5 integers hon. Phir uske har element ko 2 se multiply karke ek nayi list `doubled` mein store karein.

Mini Project

Ek simple phone directory banayein jo dictionary use kare. User se name aur phone number input le aur dictionary mein store kare. Phir user ko search karne ka option dein.

تصور

لسٹس، ٹیوپلز اور ڈکشنریز پائیتھن کے بنیادی ڈیٹا سٹرکچرز ہیں جو متعدد آئٹمز کو محفوظ کرتے ہیں۔ لسٹس ترتیب وار اور تغیر پذیر (تبدیل ہونے کے قابل) ہوتی ہیں، ٹیوپلز ترتیب وار اور غیر تغیر پذیر (تبدیل نہ ہونے کے قابل) ہوتے ہیں، جبکہ ڈکشنریز کلید-قیمت جوڑوں کو محفوظ کرتی ہیں۔ ان کے ذریعے آپ پیچیدہ ڈیٹا کو منظم اور تبدیل کر سکتے ہیں۔

مثال

# List example
fruits = ["apple", "banana", "cherry"]
fruits.append("orange")  # List میں شامل کریں
print(fruits[1])  # آؤٹ پٹ: banana

# Tuple example
colors = ("red", "green", "blue")
print(colors[0])  # آؤٹ پٹ: red

# Dictionary example
student = {"name": "Ali", "age": 20, "grade": "A"}
print(student["name"])  # آؤٹ پٹ: Ali

مشق

ایک لسٹ `numbers` بنائیں جس میں ۵ انٹیجرز ہوں۔ پھر اس کے ہر عنصر کو ۲ سے ضرب دے کر ایک نئی لسٹ `doubled` میں محفوظ کریں۔

چھوٹا پروجیکٹ

ایک سادہ فون ڈائریکٹری بنائیں جو ڈکشنری استعمال کرے۔ صارف سے نام اور فون نمبر ان پٹ لے کر ڈکشنری میں محفوظ کریں۔ پھر صارف کو تلاش کرنے کا آپشن دیں۔
