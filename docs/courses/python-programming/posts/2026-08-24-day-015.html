Day 15 — Object-Oriented Programming: Encapsulation aur Abstraction

↩️ Pichla lesson: Day 14 — Object-Oriented Programming: Inheritance aur Polymorphism — aaj is se aage badhte hain.

🎬 AI Video Explanation

Concept

Encapsulation aur abstraction OOP ke do powerful concepts hain jo code ko secure aur maintainable banate hain. Encapsulation ka matlab hai data aur uske functions ko ek single unit (class) mein bundle karna, jabki abstraction ka matlab hai complex details ko chhupa kar sirf zaroori functionality provide karna.

Example

class BankAccount:
    def __init__(self, balance=0):
        self.__balance = balance  # Encapsulation: private variable

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            print(f"Deposited: {amount}")

    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            print(f"Withdrawn: {amount}")
        else:
            print("Insufficient balance!")

    def get_balance(self):  # Abstraction: sirf balance show karna
        return self.__balance

Practice

Ek `Student` class banayein jisme `name` aur `marks` private variables hon. `add_marks()` aur `get_percentage()` methods banaen. `get_percentage()` sirf percentage return kare.

Mini Project

Ek `LibraryBook` class banayein jo `title`, `author`, aur `is_available` (private) store kare. `borrow()` aur `return_book()` methods banaen jo availability check karein. `get_status()` se book ki availability pata chale.

کنسیپٹ

انکپسولیشن اور ابسٹریکشن آبجیکٹ اورینٹڈ پروگرامنگ کے دو طاقتور تصورات ہیں جو کوڈ کو محفوظ اور قابلِ انتظام بناتے ہیں۔ انکپسولیشن کا مطلب ہے ڈیٹا اور اس کے فنکشنز کو ایک ہی یونٹ (کلاس) میں بند کرنا، جبکہ ابسٹریکشن کا مطلب ہے پیچیدہ تفصیلات کو چھپا کر صرف ضروری فعالیت فراہم کرنا۔
