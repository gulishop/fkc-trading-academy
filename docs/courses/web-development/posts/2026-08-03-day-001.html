Day 1 — HTML Basics: Apni Pehli Webpage Banana

🎬 AI Video Explanation

Concept

HTML (HyperText Markup Language) webpages ki backbone hai. Isse hum apne content ko structure dete hain—jaise headings, paragraphs, images aur links. Har webpage ek `<html>` tag se shuru hoti hai, jisme `<head>` (metadata ke liye) aur `<body>` (visible content ke liye) hote hain.

Example

Ek basic HTML file banane ke liye:

<!DOCTYPE html>
<html>
<head>
    <title>Meri Pehli Webpage</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>Ye meri pehli webpage hai.</p>
    <a href="https://google.com">Google par jao</a>
</body>
</html>

1. `!DOCTYPE html` browser ko batata hai ye HTML5 hai.
2. `<html>` root tag hai.
3. `<head>` mein page ka title aur metadata hota hai.
4. `<body>` mein jo content dikhna hai, wo hota hai.

Practice

Apni `index.html` file banao aur usme:
- Ek `<h2>` heading add karo: "Mera Pehla Project"
- Ek `<p>` paragraph add karo: "Ye mera practice ka hissa hai."
- Ek `<a>` link add karo jo "Google" par le jaaye.

Mini Project

Ek 3-page website banao:
1. `index.html` (homepage)
2. `about.html` (apne baare mein)
3. `contact.html` (contact details)
Har page par ek navigation bar banao jo doosre pages par ja sake.

تصور

ایچ ٹی ایم ایل (ہائپر ٹیکسٹ مارک اپ لینگویج) ویب پیجز کی ریڑھ کی ہڈی ہے۔ اس سے ہم اپنے مواد کو ساخت دیتے ہیں — جیسے ہیڈنگز، پیراگرافس، تصاویر اور لنکس۔ ہر ویب پیج ایک `<html>` ٹیگ سے شروع ہوتا ہے، جس میں `<head>` (میٹا ڈیٹا کے لیے) اور `<body>` (نظر آنے والے مواد کے لیے) ہوتے ہیں۔

مثال

ایک بنیادی ایچ ٹی ایم ایل فائل بنانے کے لیے:

<!DOCTYPE html>
<html>
<head>
    <title>میری پہلی ویب پیج</title>
</head>
<body>
    <h1>ہیلو ورلڈ!</h1>
    <p>یہ میری پہلی ویب پیج ہے۔</p>
    <a href="https://google.com">گوگل پر جاؤ</a>
</body>
</html>

١۔ `!DOCTYPE html` براؤزر کو بتاتا ہے کہ یہ ایچ ٹی ایم ایل ٥ ہے۔
٢۔ `<html>` روٹ ٹیگ ہے۔
٣۔ `<head>` میں پیج کا ٹائٹل اور میٹا ڈیٹا ہوتا ہے۔
٤۔ `<body>` میں جو مواد نظر آنا ہے، وہ ہوتا ہے۔

مشق

اپنی `index.html` فائل بنائیں اور اس میں:
- ایک `<h2>` ہیڈنگ شامل کریں: "میرا پہلا پروجیکٹ"
- ایک `<p>` پیراگراف شامل کریں: "یہ میری مشق کا حصہ ہے۔"
- ایک `<a>` لنک شامل کریں جو "گوگل" پر لے جائے۔

چھوٹا پروجیکٹ

ایک تین صفحات والی ویب سائٹ بنائیں:
١۔ `index.html` (ہوم پیج)
٢۔ `about.html` (اپنے بارے میں)
٣۔ `contact.html` (رابطے کی تفصیلات)
ہر پیج پر ایک نیویگیشن بار بنائیں جو دوسرے صفحات پر جا سکے۔
