🎨 Graphic Design (Canva) · Day 01

Day 1 — Canva Ka Pehla Parichay: Interface aur Basic Controls

Concept

Aaj hum Canva ke dashboard aur uski basic settings se familiar honge. Canva ek drag-and-drop design tool hai jo beginners ke liye bhi bohat aasan hai. Yahan templates, elements (shapes, icons, etc.), text options, aur upload features milte hain. Pehle hum iske interface ko samajhein gaye takay agle lessons mein confidently kaam kar saken.

Example

1.

Sign Up/Login

Canva.com par jayein, Google ya email se account banayein.
2.

Homepage

Left side mein "Create a design" button par click karen. Yahan se custom size (jaise 1080x1080px for Instagram) ya pre-set templates (jaise "Instagram Post") select karen.
3.

Interface Breakdown

-

Top Bar

Undo/Redo, save, share, aur export options.
-

Left Panel

Templates, elements (icons, shapes), text, uploads, aur background options.
-

Canvas

Apna design yahan banayein—drag karke elements add karen.
-

Right Panel

Har selected element ki properties (color, size, effects) edit karen.

Practice

Ek naya design create karen (jaise "Facebook Post" template). Left panel se ek "Text" box add karen, usme apna naam type karen, aur right panel se font style aur color change karen.

Mini Project

Ek simple Instagram Post (1080x1080px) banayein jisme:
- Ek background color ho (left panel > "Background" > color pick karen).
- Ek text box ho "Hello World!" (font: "Poppins", color: white).
- Ek simple shape (jaise circle) add karen (left panel > "Elements" > "Shapes").
